# 재량 매매 + 알고 관리 하이브리드 정책

> 종목분석 에이전트 → 알고리즘 매매 에이전트 전달용
> 작성일: 2026-05-19

---

## 개요

사용자 재량 매매 포지션을 알고 엔진이 자동 관리하는 하이브리드 구조.
"무엇을 언제 살지"는 사용자, "언제 팔지"는 엔진.
사용자가 주의력을 놓쳐도 ATR 손절/트레일링/목표가가 자동 발동하여 리스크 관리.

---

## 3채널 운영 구조

| 채널                  | 증권사   | 매수 주체              | 청산 주체            | 위험도    |
| --------------------- | -------- | ---------------------- | -------------------- | --------- |
| ISA 적립식            | 삼성증권 | 사용자 (정액 자동이체) | 사용자 (장기 보유)   | 낮음      |
| 알고 자동매매         | 토스증권 | 엔진 (A1~A6 정책)      | 엔진 (ATR + 레짐)    | 중간      |
| 재량 매매 + 알고 관리 | 토스증권 | **사용자**             | **엔진** (아래 정책) | 중간~높음 |

---

## 재량 매매 포지션 등록

사용자가 매수 후 알고 엔진에 포지션을 등록한다. 등록 시 필수 입력:

```
필수:
  - ticker: 종목 코드 (예: 005930)
  - qty: 수량
  - entry_price: 매수가
  - strategy_type: swing | position | value

선택:
  - note: 매수 근거 메모
  - custom_stop_pct: 사용자 지정 손절률 (기본값 사용 시 생략)
```

---

## 전략 유형별 엔진 파라미터

| 파라미터             | swing (단기)       | position (중기)    | value (장기)   |
| -------------------- | ------------------ | ------------------ | -------------- |
| 예상 보유 기간       | 1~4주              | 1~6개월            | 6개월+         |
| ATR 배수             | 2x (타이트)        | 2.5x (보통)        | 3x (느슨)      |
| 고정 손절률          | 8%                 | 12%                | 15%            |
| 트레일링 전환 수익률 | 10%+               | 15%+               | 25%+           |
| 목표가 손익비 (R:R)  | 2:1                | 3:1                | 5:1            |
| 보유 기간 초과 청산  | 20거래일 + 손실 시 | 60거래일 + 손실 시 | 없음           |
| 매크로 긴급 청산     | VIX 25+ 적용       | VIX 25+ 적용       | VIX 30+만 적용 |
| USD/KRW 긴급 청산    | 1,550+ 적용        | 1,550+ 적용        | 1,600+만 적용  |

### 전략 유형 선택 기준

- **swing**: 실적 발표 전 매수, 단기 이벤트 베팅, 기술적 반등 노림
- **position**: 섹터 순환, 매크로 방향성 베팅, 스코어 B등급 확신 종목
- **value**: 저평가 역발상, PER/PBR 극단 저평가, 구조적 턴어라운드 기대

## 엔진 자동 관리 로직

### 1. 초기 손절가 산출 (매수 등록 즉시)

```python
fixed_stop = entry_price * (1 - fixed_stop_pct / 100)
atr_stop   = entry_price - (atr_14 * atr_multiplier)
initial_stop = max(fixed_stop, atr_stop)
target_price = entry_price + ((entry_price - initial_stop) * rr_ratio)
```

### 2. 매일 장 마감 후 자동 갱신

```
1. ATR(14) 갱신
2. current_high = max(기존, 당일 고가)
3. 트레일링 전환 조건 확인
4. 전환 후: trailing_stop = current_high - (atr_14 * atr_multiplier)
5. final_stop = max(trailing_stop, prev_stop)  # 래칫: 하향 금지
```

### 3. 자동 매도 트리거

```
if current_price <= final_stop:
    → 전량 매도 (손절 또는 트레일링 익절)

if current_price >= target_price:
    → swing: 전량 매도
    → position: 50% 매도 + 나머지 트레일링 유지
    → value: 트레일링만 유지 (목표가 무시)

if 보유일 > 기간상한 AND 수익률 < 0:
    → 전량 매도 (자본 효율 저하 방지)
    → value는 해당 없음

if 매크로 긴급 트리거 발동:
    → swing/position: VIX 25+ 시 트레일링 1x ATR로 타이트화
    → value: VIX 30+ 시에만 적용
```

### 4. 매도 후 사용자 알림

```
매도 실행 시 알림 발송:
  - 종목명, 매수가, 매도가, 수익률
  - 매도 사유 (손절/트레일링익절/목표도달/기간초과/긴급)
  - 재진입 차단 기간 (해당 시)
```

## 재진입 차단 정책

| 매도 사유            | 차단 기간       | 재진입 조건                                 |
| -------------------- | --------------- | ------------------------------------------- |
| ATR 손절             | 10거래일        | 차단 해제 + 재분석 스코어 85+               |
| 기간 초과 청산       | 5거래일         | 차단 해제 + 신규 촉매 확인                  |
| 목표가 도달          | 없음            | 즉시 가능 (RSI < 70 + 현재가 < 이전 목표가) |
| 매크로 긴급          | 레짐 정상화까지 | 레짐 전환 확인                              |
| 동일 종목 2연속 손절 | 90거래일        | 장기 차단 (모델 부적합 판정)                |

## 리스크 관리 효과

재량 매매의 3대 위험을 엔진이 구조적으로 차단:

| 위험                            | 사용자 단독 시           | 엔진 관리 시                                   |
| ------------------------------- | ------------------------ | ---------------------------------------------- |
| 손절 지연 ("더 떨어질 리 없어") | 감정적 버티기 → MDD 확대 | ATR 래칫 자동 발동, 감정 개입 불가             |
| 익절 실패 ("더 오를 거야")      | 수익 전부 반납           | 트레일링 스탑이 수익 보호, 하향 금지           |
| 방치 ("바빠서 못 봤어")         | 급락 시 대응 불가        | 매일 15:40 자동 점검 + 긴급 트리거 24시간 감시 |

## 사용자 권한 (엔진 오버라이드)

사용자는 엔진의 자동 매도를 사전에 차단할 수 있다:

```
override 명령:
  - hold_override: true  → 해당 종목 자동 매도 일시 중단 (수동 관리)
  - cancel_override       → 다시 엔진 관리로 복귀

주의: override 중에는 모든 리스크가 사용자 책임.
      VIX 30+ 극단 상황에서도 매도 안 됨.
```
