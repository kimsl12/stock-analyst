# 삼성전자 Q3 2026 예비실적 — 메모리 사상 최대 vs 파운드리 적자 지속 (2026-10)

> 신규 semiconductor L2(2026-11). SK하이닉스(`skhynix_q3_2026_memory_supercycle`)와 같은 Q3 2026 메모리 슈퍼사이클을 **통합 반도체 기업(메모리+파운드리) 관점**에서 보완. SK하이닉스가 순수 메모리 베타라면, 삼성(005930)은 (a) 메모리 호황의 수혜 + (b) HBM4 의 NVIDIA 퀄 지연·추격 + (c) 파운드리 적자(TSMC 대비 열위) + (d) DX 적자 확대라는 **디버전스 스토리**를 제공. 메모리 피크 지속성에 대한 시장의 의구심(주가 -2.42%)이 가장 중요한 contrarian 신호.

## 핵심 발견 (6건)

- **영업이익 +782.5% YoY 사상 최대(규모 이례적, 예비)**: 2026-10-08 예비 가이던스 — 영업이익 약 107.4조원(+782.5% YoY, 약 783% 헤드라인), 매출 약 195조원(+126.6% YoY). LSEG SmartEstimate(컨센서스) 106.1조원을 소폭 상회(Reuters). **규모가 역사적 상식을 크게 상회 → 공식 삼성 IR 릴리스 대조 필수**(📄 [Filing] 삼성전자 3Q26 예비, 2026-10-08, via TrendForce).
- **HBM4 매출 기여 개시 + HBM 출하 +50% QoQ — Vera Rubin 연계**: HBM4 매출이 분기 중 _"began making a meaningful contribution"_, HBM 비트 출하는 QoQ 약 50% 증가(Reuters). HBM4 수요는 _"fueled by demand for NVIDIA's Vera Rubin AI accelerators"_(Hankyung). 삼성 HBM4 가 NVIDIA 공급망에 본격 진입하는 전환점(📄 [Filing] 삼성전자 3Q26 예비, 2026-10-08).
- **범용 DRAM 가격 급등 — 공급 타이트 전방위화**: 스마트폰/PC용 conventional DRAM 가격이 공급 타이트로 급등(Hankyung). 다만 범용 DRAM 비트 출하는 QoQ 대체로 flat 예상(Reuters) → 가격(ASP) 주도 마진 개선(📄 [Filing] 삼성전자 3Q26 예비, 2026-10-08).
- **DS가 영업이익의 ~99% — 반도체 쏠림**: 확정 실적(Money Today 10-29) 기준 반도체(DS) 부문 매출 약 147.1조원·영업이익 약 106.5조원, 전사 매출의 ~75%·영업이익의 ~99% 차지(📄 [Filing] 삼성전자 3Q26 확정, 2026-10-29, via Money Today). 메모리 외 부문의 이익 기여가 미미.
- **파운드리 적자 지속 — TSMC 대비 열위 확인**: 위탁생산(파운드리)은 고정비 부담·낮은 가동률로 여전히 적자 예상(Reuters). TSMC 3Q26 OM 58.7%(`foundry_equipment_q3_2026_capex`)와 극명히 대비 — 선단 파운드리 경쟁에서 삼성의 구조적 열위 지속(📄 [Filing] 삼성전자 3Q26 예비, 2026-10-08).
- **DX 적자 확대 + 주가 -2.42%(지속성 의구심)**: 모바일/가전(DX)은 2Q 첫 분기 영업적자 8천억원 → 3Q 1조원+로 적자 확대 추정. 사상 최대 실적에도 **주가는 2.42% 하락** — 메모리 고가·반도체 마진의 지속 가능성에 대한 시장 의구심(📄 [Filing] 삼성전자 3Q26, 2026-10, via WebSearch 종합).

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (HBM4 진입 + 메모리 호황 full 수혜)**: HBM4 매출 기여 개시 + HBM 출하 +50% QoQ + Vera Rubin 수요는 삼성이 SK하이닉스 단독 우위 구도에 본격 진입함을 의미 — HBM 3강 체제 정착 시 삼성 메모리 밸류 재평가. 범용 DRAM 가격 급등은 레거시 캐파까지 수익화. 005930 직접 + 소부장(국내) 낙수.
- **Bear case (쏠림·피크·파운드리 적자)**: 영업이익의 ~99%가 DS(메모리)에서 나오는 극단적 쏠림은 메모리 사이클 반전 시 전사 이익의 절벽 하락 리스크. 파운드리 적자 지속(TSMC OM 58.7% 대비)은 선단 노드 경쟁력 열위를 재확인 — 2nm/GAA 수율·고객 확보 실패 시 구조적 할인. DX 적자 확대는 비메모리 포트폴리오 약화. +782.5% YoY·+126.6% 매출은 기저효과이자 피크 신호.
- **Contrarian (사상 최대 실적에 주가 하락 = 피크 프라이싱 경고)**: 가장 주목할 신호는 **사상 최대 영업이익에도 주가가 2.42% 하락**했다는 점 — 시장이 메모리 고가·마진의 '지속 불가능성'을 이미 가격에 반영하기 시작. 이는 SK하이닉스의 '공급부족 2030까지' 낙관과 정면 대비되는 수급 반전 조기 경고일 수 있음. HBM4 의 NVIDIA 퀄 진전은 호재지만, 삼성·SK·마이크론 3사의 동시 HBM capex 급증이 2028+ 공급과잉의 씨앗. 메모리 피크 판정 시 '실적 vs 주가 디버전스'를 핵심 지표로.
