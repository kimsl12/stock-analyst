# VLSI Symposium 2026 — 'Memory is the Bottleneck', 3D Memory 포커스 (2026-06-14~18)

## 핵심 발견 (5건)

- **테마 = AI 프론티어 × VLSI**: 2026 IEEE/JSAP Symposium on VLSI Technology & Circuits 가 **2026-06-14~18 호놀룰루 Hilton Hawaiian Village** 에서 개최, 테마는 _"Advancing the AI Frontier Through VLSI Innovation"_ (📄 Semiconductor Digest). 본회의 후 다음 주부터 OnDemand 제공. ISSCC(2월·메모리 양산 시연)에 이은 상반기 2대 반도체 컨퍼런스로, ISSCC가 '제품 시연'이면 VLSI는 '차세대 스케일링 로드맵'에 무게.
- **Micron 기조 — '메모리가 1차 병목'**: 기조 연사 4인은 **OpenAI · TSMC · Micron · Tokyo Electron** (AI 인프라·어드밴스드 패키징·메모리 혁신·장비). 그 중 Micron Nirmal Ramaswamy 기조가 _"memory now emerging as the primary bottleneck in advanced systems"_ 라고 명시 — DRAM·NAND·HBM 을 **패키징 혁신과 함께** 발전시켜야 한다는 메시지. AI 가속의 제약이 로직(연산)에서 메모리(대역폭·용량)로 이동한다는 산업 공식 선언.
- **3D Memory(Flash·HBM) 포커스 세션**: 기술 포커스 세션 2건 — ① Advanced 3D Logic ② **3D Memory (Flash & HBM) Technology**. HBM 이 패키징 적층(12-Hi·16-Hi)에서 한계에 다가가며, 차세대는 3D DRAM 셀 구조·하이브리드 본딩으로 전환. ISSCC HBM4 양산 시연과 연속선상.
- **단기강좌 — Beyond 6F2 차세대 DRAM**: 기술 단기강좌 _"Technologies Shaping the Future as Key Enablers for AI"_ 가 **"Beyond 6F2 — Scaling Frontiers and Future DRAM, Emerging NV Memories"** + Heterogeneous Integration + Oxide Semiconductors for 3D Integration + Advanced Optical Interconnects for AI Computing 를 다룸. 현행 6F2 DRAM 셀 미세화 한계 → 4F2·3D DRAM 전환이 차세대 메모리 스케일링의 핵심 변수.
- **기업 영향 — 메모리 3강 + 장비 + 패키징**: 기조에 Micron(메모리)·TSMC(파운드리·패키징)·TEL(장비)·OpenAI(수요) 가 동시 등장 = HBM·3D DRAM 밸류체인 전체가 AI 수요 단일 축으로 정렬. SK하이닉스·삼성전자(미참여 기조이나 3D Memory 세션 핵심 출제자) + Micron 메모리 3강, 하이브리드 본딩 장비(어플라이드·TEL·BESI), 어드밴스드 패키징(TSMC CoWoS) 직접 베타.

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (메모리 3강 + 패키징)**: '메모리가 1차 병목' 공식화는 HBM·3D DRAM 단가·믹스 상향 thesis 직접 지지 — SK하이닉스(000660)·삼성전자(005930)·Micron(MU) 메모리 3강 펀더멘털 우호. 하이브리드 본딩 전환은 장비(AMAT·LRCX·TEL·BESI)·어드밴스드 패키징(TSMC CoWoS) 수혜. ISSCC HBM4 양산 + VLSI 3D Memory 로드맵 = 2026~2028 메모리 슈퍼사이클 시계열 보강.
- **Bear case (로드맵 ≠ 양산)**: 단기강좌·포커스 세션은 '연구 단계' 로드맵 — Beyond 6F2·3D DRAM 양산은 2028~2030 으로, 단기 실적과 거리. '병목' 메시지는 이미 컨센서스로 가격에 반영. HBM 적층 한계 도달은 곧 단가 정점 신호로도 해석 가능(차세대 전환기 CapEx 부담).
- **Contrarian (병목 이동 = 로직 가치 재평가)**: 병목이 로직→메모리로 이동한다면 로직(GPU·파운드리)의 한계 효용 체감 = NVIDIA 단일 의존 thesis에 미세 균열. 반대로 3D DRAM·옵티컬 인터커넥트가 성숙하면 메모리 대역폭 병목 해소 → AI 추론 ASIC(Trainium·TPU·MTIA) 경제성 재평가. 메모리가 병목이면 '메모리를 가장 잘 만드는 자'가 AI 사이클의 최종 승자 — SK하이닉스 단독 우위 vs Micron·삼성 추격 구도가 핵심.
