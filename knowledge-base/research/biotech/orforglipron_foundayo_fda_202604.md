# FDA Foundayo (orforglipron) 4/1 승인 — Lilly 경구 GLP-1 first-in-class

## 핵심 발견 (5건)

- **2026-04-01 FDA 승인**: 상품명 Foundayo, 일반명 orforglipron. 적응증: 비만 또는 과체중(BMI 27+ with weight-related comorbidity) 성인.
- **일일 1정 경구 small molecule(비펩타이드) GLP-1 수용체 작용제** — 시간·식음·물 제약 없이 복용 가능 (first-in-class).
- **ATTAIN-1 Phase 3** (72주, 무작위·이중맹검·위약 대조, n=3,127, 10개국 다국가): 36mg 최고용량 군 평균 **-12.4% (-27.3 lbs)** 감량 vs 위약 **-0.9% (-2.2 lbs)**.
- 유통: LillyDirect 직접 처방 + 4/6부터 출하, 미국 retail pharmacies + telehealth 광범위 확산 예정.
- 경쟁: Novo Wegovy(주사 semaglutide), Zepbound(주사 tirzepatide)는 주사제. **경구 + 식음 제약 없음** = 복약순응도·처방 확장의 본질적 차별화.

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (LLY)**: 경구 + 식음 제약 없음 = 주사 거부감 환자 + 글로벌 신흥국 확산 (콜드체인 불필요). LillyDirect 직접 처방 채널이 처방 마진 확대. orforglipron이 tirzepatide와 동급 매출 가능 시 LLY EPS 2027~2028 추가 +15~20% 시나리오.
- **Bear case (NVO Novo Nordisk)**: Wegovy 주사 단일 의존도 높은 NVO는 경구 GLP-1 진입에 늦음. 자체 oral semaglutide 25mg 비만 적응증 승인 시점 지연 시 시장 점유율 침식 가속 가능.
- **Contrarian**: orforglipron 72주 -12.4%는 tirzepatide -22.5% 대비 감량폭 작음. 시장이 **편의성 vs 효과** 트레이드오프를 어떻게 평가할지 미지수. 경구 GLP-1이 "1차선택"이 아닌 "주사 거부 환자 한정 2차선택"으로 자리 잡을 위험. LLY 내부 카니발리제이션 (tirzepatide vs orforglipron) 시나리오도 가능.

## 한계

- ATTAIN-1은 72주 단일 기간. 장기(2~3년) 효과 지속성은 별도 trial 필요.
- 30% 환자가 부작용으로 중도이탈 (GLP-1 공통 GI 부작용). real-world 순응도 별도 추적.
- IRA 협상 대상 약물(2028~2029 가능성) — 가격 협상 시 매출 캡 가능.
- 무력화: 2026 H2 NVO oral semaglutide 25mg 비만 적응증 승인 + 비교 trial에서 동등성 입증 시 본 thesis 약화.
