# NEJM ATTAIN-1 — Orforglipron Phase 3 (경구 GLP-1)

## 핵심 발견 (5건)

- **경구 GLP-1 first-in-class**: orforglipron 은 펩타이드가 아닌 **소분자 비펩타이드 GLP-1 수용체 작용제** — 식음 제약 (semaglutide oral 제형의 30분 공복 요구) **없음** (DOI: 10.1056/NEJMoa2511774, PubMed 40960239).
- ATTAIN-1 Phase 3: 비만/과체중 성인 대상, 72주 추적, **3-dose arm (6mg, 12mg, 36mg) + placebo** 비교 다국가 무작위 이중맹검 시험. 최고용량 (36mg) 군 **체중 -12.4%** (약 -27.3 lbs / -12.4 kg) 감소.
- 2차 endpoint: 36mg 군의 **59.6%가 ≥10% 체중 감량**, **39.6%가 ≥15% 체중 감량** 달성 (Lilly IR + NEJM 본문 요약).
- 안전성 프로파일: GI 부작용 (구역·구토·설사) 가 가장 흔한 이상반응 — 경증~중등도, GLP-1 계열 기성 클래스 프로파일과 일관 (Lilly IR 보도자료). SAE 발생률 placebo 대비 비유의.
- **LLY Foundayo (orforglipron) 4/1 FDA 승인** — 본 ATTAIN-1 결과 + 보조 trials 데이터 패키지 기반. 처방 채널·복약 순응도 (injectable 주 1회 vs 경구 일 1회) 측면에서 시장 구조 재편.
- GLP-1 시장 thesis: LLY (tirzepatide-Zepbound 주사 + orforglipron-Foundayo 경구) **이원 제형 라인업 완성** — Novo Nordisk (semaglutide-Wegovy 주사 + oral Rybelsus 제한적) 대비 경구 채널 우위.

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (LLY 압도적 GLP-1 지배력)**: orforglipron 경구 + tirzepatide 주사 이원 라인업 = NVO 대비 채널 우위. 경구 채널 시장 침투 (의료 인프라 약한 지역·고령 환자) 본격화 시 LLY 마진 + 점유율 thesis 격상. 2030 GLP-1 시장 $200B 추정 중 LLY 40%+ 점유 시나리오.
- **Bear case (가격 압력 + IRA 협상 노출)**: GLP-1 경구 제형 진입 시 가격 경쟁 가속 — semaglutide 경구 (Rybelsus) 단가 인하, NVO 신규 경구 파이프라인 (CagriSema 경구 후속) 진입 시 LLY 마진 압박. IRA 4차 협상 (2027-28) 에서 GLP-1 핵심 약물 협상 대상 가능 (이미 semaglutide 1차 협상 대상).
- **Contrarian (장기 안전성 + 적응 정체)**: GLP-1 약물 중단 후 체중 리바운드 (STEP-1 결과 1년 후 2/3 회복) 이슈 + 장기 사용 (≥ 3년) 안전성 데이터 부재. 또한 GLP-1 시장 침투율이 이미 비만 환자의 5~7% 도달 — 추가 침투 한계 가능성 (보험 커버리지 + 가격 + 부작용 내성).

## 한계

- 본 요약은 ATTAIN-1 1차 endpoint 기반 — 2차 endpoint (대사 지표·HbA1c·혈압) 별도 분석 필요.
- 72주 시점 결과 — 장기 (≥ 3년) 데이터 부재.
- 경구 제형 흡수율은 환자별 변동 가능 — clinical practice 에서 effect size 가 trial 보다 낮을 가능성.
- NEJM DOI 10.1056/NEJMoa2511774 확정 — NEJM 본문 paywall, abstract + Lilly IR 종합 사용. p-value, AE 발생률 정확한 % 는 본문 게재.
- 후속 trial: **ATTAIN-2** (T2DM 동반 비만 환자 대상, Lancet 게재 — PIIS0140-6736(25)02165-8) 별도 발표 — 본 KB 별도 항목 필요.
- 무력화: 2026 H2 NVO 신규 경구 GLP-1 (예: amycretin 경구 제형) Phase 3 결과 발표 시 LLY 우위 일부 잠식 가능.
