# Golden Dome 미 본토 미사일방어 — CBO $1.2조 추정 (CBO, 2026)

> 신규 defense L2(2026-11). 기존 L2(NATO 5%·대드론 스웜·미·일 동맹·FY2027 예산)와 달리 본 요약은 **미 본토 미사일방어(Golden Dome)라는 신규 메가 프로그램의 비용 아키텍처**를 다룬다 — 미사일방어·우주 방산(LMT·RTX·NOC·L3Harris·KTOS)과 FY2027 예산 논쟁에 직접 연결. `fy2027_defense_budget_topline_reconciliation`(예산 토플라인)과 짝을 이루는 프로그램 레벨 요약. defense L2 5건 누적(L3 분기 Deep Dive 요건 충족).

## 핵심 발견 (5건)

- **CBO 추정 20년 $1.2조(작년의 약 2배)**: CBO가 2026-05-12 발표한 _"Potential Costs of a National Missile Defense System"_ 는 트럼프 2025-01 행정명령 지정 본토 미사일방어를 20년간 개발·배치·운영하는 데 **2026년 달러 $1.2조**로 추정. 작년 CBO 추정의 약 2배. (📄 [Policy] CBO via SpacePolicyOnline, 2026-05)
- **취득 $1조 초과 + 운영비**: 전체 $1.2조 중 **취득비용이 $1조 초과**, 나머지가 연간 운영비. (📄 [Policy] CBO via DefenseScoop, 2026-05)
- **SBI가 비용의 지배적 항목(취득 70%·전체 60%)**: 최대 비용은 **우주기반요격기(SBI) 성좌** — 취득비의 **70%**, 전체의 **60%**. SBI 성좌 추정은 근극궤도(고도 300~500km) **위성 약 7,800기**, 20년간 **약 $7,200억** 개발·배치·유지 + **연 $10억** 운영. 초기 위성 1기당 $2,200만, 5년 수명이라 **연 ~1,600기 교체** 가정. ICBM **10발을 부스트 단계**에서 요격하는 전제. (📄 [Policy] CBO via SpacePolicyOnline, 2026-05)
- **행정부 $185억 vs CBO $1.2조 — 약 6배 괴리**: 트럼프는 2025-05 **$1,750억** 배치 비용을 제시, 현재 **$185억**이 이미 편성(2026-03 우주역량 **$100억 추가** 승인 포함). CBO는 DoD 추정이 자신보다 훨씬 낮은 것은 **DoD 아키텍처가 더 제한적이거나 다른 계정으로 자금 조달**하기 때문일 수 있다고 지적. (📄 [Policy] CBO via DefenseScoop, 2026-05)
- **아직 목표 아키텍처 미확정 → '가상' 설계로 추정**: CBO는 DoD가 아키텍처·포함 시스템을 거의 공개하지 않아 **행정명령 기반 가상(notional) 설계**로 추정했으며, 구체 계획 없이는 장기 비용 확정이 불가하다고 명시. DoD 추정은 FY2027 예산요청과는 부합하나 더 짧은 기간·다른 범위·회계 분류를 쓸 수 있음. (📄 [Policy] CBO via DefenseScoop, 2026-05)

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (초대형 신규 수요풀)**: $1.2조 추정(취득 $1조+)은 미사일방어·우주 방산에 수십 년 수요풀 — SBI 성좌(위성 7,800기, 연 ~1,600기 교체)는 **우주·위성 양산** 수혜(L3Harris·NOC·LMT 우주사업, 신생 우주방산). 센서·요격기·지휘통제(C2)는 RTX·LMT·NOC에 분산. 행정부가 이미 $185억 편성(+2026-03 $100억 추가)해 **프로그램이 자금과 함께 가동** — 조기 수주 가시성.
- **Bear case (비용·기술·정치 리스크)**: CBO $1.2조는 행정부 $185억의 **약 6배** — 의회가 CBO 수치에 근거해 축소·단계화하면 실제 조달은 가상 아키텍처의 일부에 그칠 수 있음. SBI(위성 7,800기, 연 1,600기 교체)는 **기술·발사 캐파·공급망** 미검증 — 일정·단가 초과 상습 리스크. FY2027 예산 자체가 CR·재정조정 불확실(참조: fy2027_defense_budget 토픽) → Golden Dome 자금도 변동. 정권 교체 시 우선순위 반전 가능.
- **Contrarian (아키텍처 미확정 = 수치 신뢰도 낮음)**: CBO 스스로 '목표 아키텍처 미확정'이라 **가상 설계**로 추정 — $1.2조는 상한 성격이고 DoD 실제 설계는 '더 제한적'일 수 있다(CBO 명시). 즉 $1.2조도 $185억도 모두 확정 아키텍처가 아닌 가정 위의 숫자. SBI 중심 설계가 지상·광역 요격 중심으로 재편되면 수혜 종목 믹스가 통째로 바뀜 — '우주 성좌 수혜' 서사에 조기 베팅은 리스크. 밸류에이션 선반영 여부 점검 필요.
