# IRA 30D 클린비클 크레딧 = 신산업정책 (SIEPR Stanford)

> [paywalled/403: abstract only] — siepr.stanford.edu 및 cars.stanford.edu(→sustainablemobility.stanford.edu 리다이렉트) 직접 WebFetch 가 모두 HTTP 403. 본 요약은 검색 엔진이 추출한 페이지 본문 + abstract 레벨 정보 기반. 정확한 계량 추정치(납세자 비용 $/톤 CO2, 점유율 변화 %)는 SIEPR 원문 PDF 게재 — 본 요약 미접근.

## 핵심 발견 (5건)

- **IRA 30D = 산업정책 회귀 사례**: SIEPR 은 IRA 의 클린비클(Clean Vehicle) 세액공제를 미국 **산업정책(industrial policy) 부활** 의 대표 사례로 분석. 기존 EV 크레딧을 대체해 ① 소비자 신차 EV/PHEV, ② 상업용, ③ 중고 EV/PHEV 세 종류로 재편.
- **이원 $3,750 구조 (원산지 요건)**: 단일 $7,500 크레딧 → **두 개의 $3,750 크레딧** 으로 분할 — 하나는 **배터리 부품 원산지(battery component origin)**, 다른 하나는 **핵심광물 원산지(critical mineral origin)** 충족 조건. 공급망 리쇼어링·프렌드쇼어링을 직접 인센티브화.
- **자격 요건 (3종)**: ① **북미 조립(North America assembly)**, ② 차량 가격 상한 + 구매자 소득 상한, ③ 배터리 부품·핵심광물 원산지 요건. **2032년까지** 연장.
- **SIEPR 비용-편익 평가**: IRA EV 크레딧이 **기후 변화 완화 + 미국 제조 기업으로 생산 이전** 효과는 있으나, **납세자에게 높은 비용** 부과. 차등(differentiated) 크레딧으로 더 깨끗한 차량을 우대했다면 효율적이었을 것이라는 정책 제언.
- **함의 (산업정책 + 리쇼어링)**: 원산지 요건은 미국·동맹 배터리·광물 공급망 투자 유인 — 미국 내 배터리·EV 조립 플랜트 입지 가속. 단, 요건 충족 모델 수 제한 → 단기 소비자 선택지·크레딧 적용 차량 축소 가능.

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (미국 EV·배터리 리쇼어링 수혜)**: 원산지 요건은 북미 배터리·광물 공급망 투자 직접 유인 — 미국 내 조립·배터리 플랜트 보유 OEM(Tesla, GM)·배터리(LG엔솔·SK온·삼성SDI 미국 합작) 가 크레딧 적격 유지로 상대 우위. Tesla Model 3/Y, GM Lyriq/Bolt 등 후속 IRA 적격 재진입. 가격 갭 축소 → EV 침투 가속.
- **Bear case (수요 풀인 + 크레딧 종료 절벽)**: 요건 단계 상향(부품 90%·100%, 광물 80%) 으로 적격 모델 축소 가능. L1 의 "연방 EV 크레딧 9/30 종료" 시나리오 부상 시 사이클 후반부 수요 풀인(pull-in) 후 절벽 — 종료 후 EV 수요 급감 리스크. SIEPR "납세자 비용 높음" 은 정책 지속성·축소 압력 시사.
- **Contrarian (산업정책 효율성 논쟁)**: SIEPR 의 핵심 메시지는 "효과는 있으나 비효율적" — 크레딧이 차량 청정도와 무관하게 일괄 지급돼 한계 효율 낮음. 정책 변동(축소·종료·차등화) 시 EV 수요·OEM 마진 충격. EV 크레딧 의존 수요는 구조적이 아닌 정책적 — 크레딧 없는 EV 가격 경쟁력이 본질.
