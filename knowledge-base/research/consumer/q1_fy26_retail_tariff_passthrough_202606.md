# Q1 FY26 미국 리테일 어닝 — 관세 가격 전가 본격화 (2026-05)

## 핵심 발견 (5건)

- **Walmart — e커머스 첫 흑자 + 관세 가격 인상 예고**: Q1 FY26 매출 $164.0B, 영업이익 $7.1B, 조정 EPS **$0.61**. 미국 e커머스가 광고·풀필먼트 수익 포함 시 **첫 흑자** 달성 — CFO John David Rainey _"a milestone moment."_ 4,600개 슈퍼센터를 당일 풀필먼트 허브로 활용해 24시간 내 93% 가구 도달 (📄 Walmart Q1 FY26, 2026-05-15).
- **Walmart 관세 전가 명시 (가장 직접적 신호)**: CFO Rainey _"I'm concerned that consumer is going to start seeing higher prices. You'll begin to see that, likely towards the tail end of this month, and then certainly much more in June."_ — 관세 비용의 소비자 전가 시점을 **5월 말~6월** 으로 구체화. 리테일 → CPI 전이 채널의 1차 증거.
- **Target — 동일점 반전 + 가이던스 상향**: Q1 FY26 GAAP·조정 EPS 동일 **$1.71**, 순매출 **+6.7%**, 동일점매출 **+5.6%**, 디지털 동일점 **+8.9%** (당일배송 +27% 초과). 6개 핵심 머천다이징 카테고리 전부 성장(건강·웰니스·문화·완구 두 자릿수). 연간 가이던스 상향 (매출 +4% 내외, EPS $7.50~8.50 상단) — 전분기 부진 대비 반전 (📄 Target Q1 FY26, 2026-05-20).
- **Home Depot — 관세 환급 신청 + 선별적 인상**: 순매출 **$41.8B (+4.8% YoY)**, 동일점 +0.6%(미국 +0.4%). 연간 가이던스 재확인. CFO McPhail — 연료비·원자재·신규 관세 비용 압력 인정하되 **관세 환급(refund) 신청** 으로 상쇄 기대, _전면 인상 아닌_ 카테고리별 선별적 가격 조정 (📄 Home Depot Q1 FY26, 2026-05-19).
- **공통 테마 — 관세 전가의 리테일러별 차별화**: Walmart(5월 말~6월 인상 예고, 가장 공격적) > Home Depot/Lowe's(선별적·환급 상쇄) 의 스펙트럼. Target 은 가이던스 상향이지만 관세 환급분 제외 기준 — 관세 비용이 리테일 마진·소비자 가격으로 이전되는 구조적 분기.

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (대형 리테일러 가격 결정력)**: 관세 전가 능력 = 가격 결정력 입증. Walmart e커머스 흑자 전환 + Target 디지털 +8.9% 는 옴니채널 구조 우위. 대형 리테일러는 관세 비용을 소비자·벤더에 분산할 협상력 보유 — 마진 방어. Walmart(저가 포지셔닝·필수재 비중) 는 관세發 인플레 국면에서 트레이드다운 수혜 가능.
- **Bear case (소비자 지갑 압박 + 마진 스퀴즈)**: 관세 전가 = 소비자물가 상승 = 실질 구매력 하락 → 재량소비(discretionary) 둔화. Home Depot 동일점 +0.6% 의 약한 주택 매크로 + Lowe's CEO "challenging housing macro" 인정. 관세 비용을 전부 전가 못 하면 마진 스퀴즈 — 특히 임의소비·내구재 비중 높은 리테일러.
- **Contrarian (관세 인플레 일시적 vs 구조적)**: 관세 가격 인상이 일회성 레벨 점프인지 지속 인플레인지 미확정. Home Depot 의 관세 환급 신청은 비용 상쇄 채널 존재를 시사 — 전가 압력이 과대평가됐을 가능성. 또한 Target 의 가이던스 상향은 소비 위축 우려와 상충 — "관세 = 소비 붕괴" 내러티브가 과장됐을 수 있음.
