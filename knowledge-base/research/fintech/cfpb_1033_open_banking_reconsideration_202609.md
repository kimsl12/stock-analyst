# CFPB Section 1033 오픈뱅킹 규칙 집행정지 + 재검토 (2026)

> fintech L2 보강분(2026-09). 기존 7건은 전부 **스테이블코인·크립토 규제**(GENIUS Act·BIS 스테이블코인·SEC-CFTC token taxonomy·OCC 준비금) 축이었다. 본 요약은 **오픈뱅킹·소비자 금융데이터권(Section 1033)** 이라는 새 규제 축을 추가한다 — 결제·디지털뱅킹·데이터 애그리게이션 밸류체인(V·MA·PYPL·SOFI·애그리게이터)에 직접 파급되는 규제 재편으로, 크립토와 별개의 핀테크 규제 트랙.

## 핵심 발견 (5건)

- **2026-04-01 준수시한 무력화**: Section 1033 최종규칙(2024-11 확정)의 첫 준수시한(대형 예금기관·대형 비예금 데이터제공자)이 **2026-04-01 도래했으나 집행 없이 경과**. 원문 인용 _"The April 1 date arrived, but not as a binding enforcement trigger."_ (📄 [Think Tank] Cozen O'Connor, 2026-04)
- **연방법원 집행정지 가처분**: 켄터키 동부지법(E.D. Kentucky)이 CFPB의 규칙 집행을 막는 **가처분(injunction)** 발령 — 은행·업계 단체 소송에 따른 조치. 규칙 자체는 폐지되지 않았으나 집행 불가 상태. (📄 [Think Tank] Cozen O'Connor, 2026-04)
- **CFPB 자체 재검토 → 신규 NPRM OIRA 제출**: CFPB가 2025-08 ANPRM으로 재검토 착수 후, **2026-08-05 신규 NPRM('Personal Financial Data Rights Reconsideration')을 OIRA에 제출**. 규칙의 수정·철회 여부를 심사 중. (📄 [Think Tank] Cozen O'Connor, 2026-04; 📄 [Think Tank] PYMNTS, 2026-08)
- **데이터 접근 수수료 허용 검토(핵심 쟁점)**: CFPB가 _"assessment of fees to defray the costs incurred by a 'covered person' in responding to a customer-driven request"_ 를 검토 — 즉 **은행이 애그리게이터·제3자에게 데이터 접근 비용을 청구**할 수 있게 허용하는 방향. 무료·표준 API 개방을 전제한 원 규칙의 근본 전제를 뒤집는 변화. (📄 [Think Tank] PYMNTS, 2026-08)
- **이해 정면 충돌**: 핀테크·오픈뱅킹 진영은 Section 1033을 _"a pro-competition consumer right"_ 로 옹호, 은행·업계 단체는 **소비자 데이터 보안 위험**을 이유로 반대. '대리인(representative)' 정의·데이터 보안·프라이버시가 추가 쟁점. (📄 [Think Tank] PYMNTS, 2026-08; 📄 [Think Tank] Cozen O'Connor, 2026-04)

## 분석가 활용 가이드 — Bull / Bear / Contrarian

- **Bull case (은행·데이터 소유자 우위)**: 수수료 부과 허용 시 대형 은행·데이터 제공자(JPM·BAC 등)가 **데이터 접근을 수익화**하고 애그리게이터 협상력을 흡수 → 무료 개방 부담 경감. 규칙 집행정지·재검토는 은행권 컴플라이언스 비용·API 강제 개방 리스크를 지연시킴. 규제 불확실성 해소 시(어느 방향이든) 결제·뱅킹 인프라(V·MA·FIS·FISV) 투자 가시성 개선.
- **Bear case (애그리게이터·핀테크 마진 압박)**: 무료·표준 API 개방을 사업모델 전제로 삼은 **데이터 애그리게이터(Plaid 등)·핀테크(PYPL·SOFI·NU 등)** 는 접근 수수료 도입 시 원가 상승·마진 압박. 규칙 자체가 집행정지·재검토로 **표류(limbo)** 하면 오픈뱅킹發 신규 성장 서사(계좌 연결·데이터 기반 신용평가)가 지연. 스크린 스크래핑 대체 표준 부재 시 보안·안정성 리스크 잔존.
- **Contrarian (규제 방향 반전 리스크·시장 과소반영)**: '오픈뱅킹=핀테크 순풍'이라는 통념과 반대로, 미국판 1033은 **수수료·집행정지·정권 재검토**로 EU PSD2식 무료 개방과 다른 경로를 갈 수 있음 — 애그리게이터 밸류에이션에 내재된 '무료 데이터 접근' 가정이 과대평가일 수 있음. 반대로 최종 규칙이 소비자권 강화로 유지되면 은행권이 흡수할 컴플라이언스 비용이 과소반영. 어느 쪽이든 현 컨센서스가 한 방향에 치우쳐 있으면 미스프라이싱.

- 본 요약은 **법무법인 규제 알림(Cozen O'Connor) + 업계 매체(PYMNTS) fetch 기반** — CFPB 원 규칙·연방관보(Federal Register)·법원 판결문·OIRA 심사 문서는 딥페치 미수행. 정량·법리 인용 시 consumerfinance.gov 원문·Federal Register 재확인 권장(congress.gov CRS IF13117·Consumer Finance Monitor는 본 세션 403/미접근).

- 무력화 조건: (1) OIRA 심사 후 CFPB가 규칙 철회 → 오픈뱅킹 강제성 소멸(애그리게이터 서사 붕괴). (2) 법원이 가처분 해제·원 규칙 유지 → 은행 컴플라이언스 비용 현실화. (3) 수수료 부과 불허로 결론 → 무료 개방 전제 유지. (4) 정권·CFPB 리더십 변화에 따라 방향 재역전 가능(정치 사이클 의존성 높음).
