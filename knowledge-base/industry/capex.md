- **AI 비중**: 합산 CapEx의 ~75% ($450B+)가 AI 인프라 (추론 > 학습 전환)

- **2025-2027 누적**: Goldman Sachs $1.15T (2022-2024 $477B의 2.4배)
- **FCF 리스크**: Amazon 적자 전환 + Meta FCF 90% 감소. 그러나 CapEx/FCF <1x (닷컴 4x와 차별화)
- **백로그 수요**: MSFT CRPO $625B(+110%), GOOGL Cloud $240B -- 수요는 강력

### 투자 방향성

```
2024 $256B -> 2025 $381-443B (+49-73%) -> 2026 $635-690B (+67-74%) -> 2027E $800B+
학습 중심 -> 추론 중심 전환 (2025~)
FCF 악화 -> 일부 적자 전환 (2026~)
부채 발행 $1.5T 필요 (MS/JPM), 2025 $121B+2026 $100B+ (BofA)
```

### 리스크 요인

```
1. ROI 정당화 위기: GS "수익 $1T 필요 vs 컨센 $450B" -- 절반 미달
   -> CapEx 급감 시나리오. GS CEO "배치자본 상당수 수익 미달" 경고

2. FCF/부채: Amazon 적자 전환, Meta FCF -90%. 기술섹터 $1.5T 신규 부채
   -> 닷컴 대비 건전(CapEx/FCF <1x vs 4x), 그러나 절대 규모 전례 없음

3. 전력 병목: 신규 DC 24-72개월 지연. 변압기/스위치기어/가스터빈 부족
   -> CapEx 집행 속도 < 계획. 전력 확보가 AI 인프라 최대 제약

4. 지정학: TSMC 대만 집중도 (글로벌 첨단 반도체 90%+)
   -> 미국/일본 현지화 비용 30-50% 프리미엄

5. 통신 정체: 5G 사이클 종료 후 6G까지 공백. 글로벌 -2% YoY
   -> 통신장비 업체 성장 둔화. AI-RAN/위성으로 전환 모색
```
