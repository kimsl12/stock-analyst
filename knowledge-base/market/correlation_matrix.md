#### #2 NASDAQ ↔ BTC — 이상 극단 (Z -3.26σ) ★ 최우선 경고

**현황 (05-13 이브닝):** NASDAQ 29,386.50 선물(+11.96% vs 05-09) / BTC ~$81,115(+1.06%). 전체 피어슨(n=13) = **-0.053** — 상관관계 사실상 소멸. Z-score **-3.26σ** (정상 양의 상관 +0.60 대비 역방향 이탈).

정상 구조(NASDAQ↔BTC 양의 동조 +0.60)에서 NASDAQ의 극단적 아웃퍼폼. 원인: 미중 무역협상 진전 + 관세 완화 합의 기대가 기술주 폭등 견인. BTC는 무역협상 수혜에서 제외 = 크립토 독립 이벤트 부재 구조.

**과거 유사 사례:** 2021년 3월 리플레이션 트레이드 국면 — NASDAQ 급등(실적 기대) vs BTC 상대 횡보(기관 매도 압력). 당시 NASDAQ↔BTC 상관 일시 붕괴 후 4~6주 내 재동조. 현재 구조는 무역협상 해결 시 BTC도 리스크온 수혜 받는 재동조 경로 가능.

**시나리오:**
1. 미중 합의 공식화 + 글로벌 리스크온 지속 → BTC도 추격 상승 → 재동조 (Z-score 정상 복귀)
2. CPI Beat 지속 + 연준 매파 강화 → NASDAQ 조정 + BTC 동반 하락 → 동조 방향으로 복귀
3. 크립토 규제/온체인 악재 독립 발생 → BTC 독립 하락 → Z-score 추가 이탈

**투자 시사점:** NASDAQ 폭등이 BTC에 미전이 = BTC의 기술주 동조 프리미엄 일시 해소. BTC 매수 관점에서는 리스크온 재동조 시점 포착 필요. NASDAQ 신고가 추종보다 BTC 저평가 창 해석 가능. 단, 탈동조가 BTC 독립 약세 신호일 가능성도 배제 불가.
