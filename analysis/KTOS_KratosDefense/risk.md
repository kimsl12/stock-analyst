## 2. Top 5 핵심 리스크 심층 분석

### 리스크 1: CCA Increment 2 탈락 (확률 40%, 영향 -30%)

**시나리오:**
- 2026 하반기 RFP -> 2027 상반기 선정
- 후보: Anduril Fury, Boeing MQ-28, KTOS Valkyrie/Mako, GA Gambit
- Anduril Fury가 1차에서 선정 - 관성 우위

**탈락 시 영향:**
- 주가 충격: -25-30% (\$74 -> \$52-55)
- 멀티플 디레이팅: PER 91 -> 60-70 (성장 스토리 약화)
- 매출 영향: 2027-2030 누적 \$2-3B 매출 기회 상실

**대응책:**
- KTOS는 가격 우위 (\$3M vs Anduril \$5-6M 추정)
- 표적기 캐시카우 + Hypersonic으로 재무 충격 흡수
- 유럽/중동 수출로 매출 보완 시도

### 리스크 2: 마진 확장 실패 (확률 35%, 영향 -20-25%)

**시나리오:**
- OPM 5% -> 8% 확장 컨센이지만 R&D + 인플레로 정체
- 2027E OPM 6.8% -> 5.5% 정도로 미달

**영향:**
- 2027E EPS \$1.05 -> \$0.80
- PER 91배 정당화 어려움
- 멀티플 디레이팅 -20-25%

**대응책:**
- Mix 개선 (UAS 비중 확대) 모니터링
- 분기마다 OPM 25-30bp 개선 확인
- 미달성 시 \$70 이하 추가 매수 보류

### 리스크 3: 밸류에이션 디레이팅 (확률 50%, 영향 -40%)

**시나리오:**
- New Defense 테마 약화 (예: 우크라/중동 휴전)
- 금리 재상승 -> 성장주 멀티플 압박
- KTOS PER 91 -> 동종 평균 65 (AVAV) -> 50

**영향:**
- 단순 멀티플 조정으로 \$74 -> \$45-50 (-35-40%)
- 펀더멘털 변동 없어도 발생 가능

**대응책:**
- 분할매수로 평균 단가 낮추기
- 2xATR 손절(\$64) 엄수
- 추세 전환(\$80 돌파) 확인 후 비중 확대

### 리스크 4: 안두릴(Anduril) 시장 잠식 (확률 50%, 영향 -15-20%)

**시나리오:**
- Anduril 추가 자금 조달 (2025 라운드 \$1.5B+)
- Lattice OS 표준화 - KTOS HW도 Anduril SW 의존
- 안두릴 IPO 시 비교 멀티플 압박

**영향:**
- KTOS 시장 점유율 점진적 잠식
- "AI 부재 디스카운트" 부각

**대응책:**
- KTOS와 Palantir/Anduril SW 협력 가능성
- 가성비/양산 차별화 강조
- 자체 SW 역량 확보 (M&A 가능성)

### 리스크 5: 이란 휴전 합의 (확률 60%, 영향 -10-15%)

**시나리오:**
- 4.21 휴전 만료 -> 추가 협상 -> 휴전 합의
- 호르무즈 봉쇄 해제, 유가 \$80대 복귀
- 단기 방산 수요 모멘텀 약화

**영향:**
- 단기 차익매물 출회 (-10-15%)
- 단, 중기 펀더멘털(국방예산, CCA)에는 영향 미미

**대응책:**
- 단기 트레이딩 시점 조정
- 장기 보유는 영향 거의 없음

## 3. 시나리오 분석 (12개월)

### Bull Case (확률 25%, 목표 \$120, +61%)
- CCA Increment 2 KTOS 선정
- OPM 7%+ 달성
- 이란 전쟁 재개 -> 표적기/UAS 수요 급증
- M&A 인수 제안 (NOC 또는 LHX) -> 프리미엄 30%

### Base Case (확률 50%, 목표 \$87, +17%)
- 매출 컨센 달성 (\$1,560M)
- 마진 점진 개선 (OPM 5.0% 컨센)
- CCA Inc 2는 분점 (Anduril 60%, KTOS 40%)
- 단계적 멀티플 회복

### Bear Case (확률 25%, 목표 \$50, -33%)
- CCA Inc 2 탈락
- OPM 정체 (4.5%)
- 이란 휴전 -> 단기 모멘텀 소멸
- 안두릴 IPO -> 멀티플 디레이팅 가속

### 가중 평균 기대수익률
- Bull: \$120 * 25% = \$30
- Base: \$87 * 50% = \$43.5
- Bear: \$50 * 25% = \$12.5
- **가중 평균 \$86 = +15.2% 기대수익**

## 4. Devil's Advocate 의견 (반대 시각)

### 매도 논리 1: "PER 91배는 어떤 가정에서도 무리"
- 아무리 New Defense라도 OPM 5%로 PER 91배는 명확한 거품
- 동급 AVAV PER 65배도 OPM 8.5% 기반 - KTOS는 OPM 절반 수준
- 적정 PER은 50-60배 수준 = 적정주가 \$45-55 = 현재가 -25-40% 과대평가

### 매도 논리 2: "CCA Inc 1 탈락은 구조적 약점 노출"
- KTOS Valkyrie가 가장 시각화된 CCA 컨셉이었음에도 1차 선정 탈락
- DoD가 KTOS의 양산 능력/AI 통합에 의문 표시한 것
- Increment 2에서 회복 가능성 낮음 (선정자 우위 관성)

### 매도 논리 3: "방산 사이클 정점 신호"
- 2024-2025 방산주 폭등은 우크라/중동 위기 모멘텀
- 휴전/평화 협상 시 멀티플 정상화 (PER 60->20)
- KTOS 2025 +135%는 정점 근처 신호

### 매도 논리 4: "안두릴 IPO 시 KTOS는 상대적 매력 상실"
- Anduril IPO 추진 (2026 하반기 또는 2027 가능성)
- IPO 시 \$50-60B 평가 가능 -> KTOS \$14B와 비교 시 소형주 디스카운트
- "원조 New Defense"는 Anduril, KTOS는 "구식 무인기"로 격하

### 매수자 반박
1. PER 91배는 현재 EPS 기준, 2027E 기준 PER 71배로 떨어지며 마진 확장 시 추가 하락
2. CCA Inc 1 탈락은 이미 주가 -28% YTD에 반영. Increment 2는 새로운 게임
3. 방산 사이클 정점이라도 국방예산 절대 규모(\$895B) + 무인기 침투율 5% -> 30% 트렌드는 구조적
4. Anduril IPO 시 KTOS도 비교 멀티플 상승 가능 (피어 효과)

### 리드 판단: 매수자 논리 우세 (확률 55%)
- 단, Devil's Advocate 우려도 현실적 - **분할매수 + 손절 엄수**
- 적정 비중: 포트폴리오 2-3% (소형 베팅)
