#### DuPont 분해 (FY2025)

```
ROE = 순이익률 × 자산회전율 × 재무레버리지
57.6% = 21.7% × (57.40/168.4=0.34) × (168.4/20.5=8.2)

→ 순이익률(21.7%) 개선 + 레버리지(8.2x) 활용
→ 자산회전율(0.34) 낮음: AI capex 자산 대비 매출 아직 성숙화 전
→ 핵심: capex 투자 자산이 OCI 매출로 전환될수록 자산회전율 개선 → ROE 자연 회복
```

#### WACC 추정

```
Rf (무위험수익률): 4.5% (미국 10년 국채, 2026-04)
Beta (β): ~1.1 (클라우드 전환 + AI 변동성)
ERP (시장위험프리미엄): 5.0%
소형주 프리미엄: 0% (대형주)
→ 자기자본 비용 = 4.5% + 1.1×5.0% = 10.0%
세후 부채비용 = 6.0% × (1-21%) = 4.74%
자본비율: E/(E+D) ≈ 20.5/(20.5+85.3) = 19.4%
부채비율: 80.6%
WACC = 10.0%×0.194 + 4.74%×0.806 = 1.94% + 3.82% = 5.76% → 반올림 ~6.0%
(단순화 주의: 시가총액 기준 시 E/(E+D) = 503.5/(503.5+85.3) = 85.5% → WACC 재산출)
시총 기준 WACC = 10.0%×0.855 + 4.74%×0.145 = 8.55%+0.69% = ~9.2%
```

> WACC 기준: 본 분석에서는 **시가총액 기준 WACC 9.2%** 사용 (시총 $503.5B, 차입금 $85.3B).
> ROIC ~12~15% > WACC 9.2% → 가치 창출 중. AI capex 투자가 회수되면 스프레드 확대.

## ▶ 5. 목표주가 산정 (Multi-Method Valuation)

### Method 1: 상대 밸류에이션 (Relative Valuation)

#### 피어그룹 선정 및 근거

| 피어 기업 | 선정 이유 | FY2026E PER(Non-GAAP) | EV/EBITDA | PSR |
|---------|---------|----------------------|-----------|-----|
| Microsoft (MSFT) | Azure AI 클라우드 직접 경쟁, 엔터프라이즈 SW | 32x | 22x | 11x |
| Amazon (AMZN) | AWS AI 인프라, 클라우드 Big-3 | 38x | 18x | 3.5x |
| Salesforce (CRM) | 엔터프라이즈 SaaS, DB 연동 생태계 | 28x | 20x | 6.5x |
| ServiceNow (NOW) | 엔터프라이즈 AI 플랫폼, 고성장 SaaS | 52x | 35x | 16x |
| SAP | ERP 직접 경쟁사, 클라우드 전환 | 30x | 24x | 7x |
| **피어 평균** | | **36x** | **23.8x** | **8.8x** |
| **피어 중간값** | | **32x** | **22x** | **7x** |
| **Oracle (현재)** | | **~21.2x** | **~21x** | **~7.0x** |
| **프리미엄/디스카운트** | | **-34% 디스카운트** | **-12%** | **-20%** |

> 피어 선정 이유: AI 클라우드(MSFT, AMZN), 엔터프라이즈 SaaS(CRM, NOW), ERP(SAP)로 Oracle 3중 포지션 반영.
> 현재 Oracle은 피어 평균 대비 Non-GAAP PER에서 -34% 디스카운트 → 저평가 신호.

#### 적정 PER 산출 (ROE 조정)

```
적정 PER = 피어 평균 PER × (Oracle ROE / 피어 평균 ROE)

Oracle ROE: 57.6% (FY2025, 부채 왜곡 내포)
피어 평균 ROE 추정: MSFT ~40%, AMZN ~25%, CRM ~18%, NOW ~30%, SAP ~28% → 평균 ~28%

단, Oracle ROE는 레버리지 왜곡이 크므로 ROIC 기반 조정:
Oracle ROIC ~12~15% vs 피어 평균 ROIC ~18%
→ 적정 PER 할인: 36x × (13.5% / 18%) = 36x × 0.75 = 27x

그러나 Oracle의 AI 인프라 피벗 + RPO $130B+ 성장 프리미엄 부분 복원:
```
