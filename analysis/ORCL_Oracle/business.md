## ▶ 산업 트렌드 개요

```
시장 규모 (클라우드 AI 인프라 + 엔터프라이즈 DB + SaaS 합산)
  현재 (2026E): ~$530B~$650B (IaaS $250~300B + SaaS $200~250B + DBMS $80~100B)
  2030E 목표:  ~$1.2T~$1.5T (클라우드 AI 인프라 단독 $700B+, CAGR 25~30%)

산업 단계: 성장기 (AI 인프라는 도입기~급성장기 전환점)
사이클 국면: 확장 (AI capex 슈퍼사이클 진입, 2024~2028E 피크 전망)
```

### 핵심 메가트렌드 & Oracle 영향

| 트렌드 | 영향 방향 | 영향도 | 근거 |
|--------|----------|--------|------|

| Sovereign AI (각국 정부 AI 자주권 경쟁) | 긍정 | 높음 | OCI Dedicated Region이 데이터 현지화 규제 대응 최적 구조. 중동·유럽·아시아 정부 고객 확보 가능 |
| 엣지 추론 시장 확대 (Inference > Training 전환) | 긍정 | 중간~높음 | 추론 수요 60%+ 비중(2025). OCI Dedicated Region + 베어메탈 GPU가 추론 TCO 최적화에 유리 |
| 오픈소스 LLM 확산 (Llama, DeepSeek) | 부정 | 중간 | DB API 단가 하락 압력. 단, 인프라 수요 확대(Jevons Paradox)로 OCI 장기 이익 가능 |

| EU AI Act 2026.08 고위험 적용, 데이터 주권 | 긍정 | 중간 | 규제 준수 부담 → 기업들이 검증된 엔터프라이즈 벤더 선호. OCI Dedicated Region 수요 증가 유인 |

### 기술 변화 핵심 키워드

- **NVIDIA Blackwell / H200 슈퍼클러스터**: OCI 32K+ GPU 단일 클러스터 운영 능력이 핵심 차별점
- **RDMA over Converged Ethernet**: 초저지연 GPU간 통신으로 대규모 모델 학습 효율 극대화
- **Autonomous Database**: AI/ML 기반 자동 패치·튜닝·보안. DBA 인건비 50%+ 절감(Oracle 발표)
- **OCI Dedicated Region**: 고객 사내 전용 OCI 인프라. 금융·정부·헬스케어 규제 대응
- **AMD MI400, Intel Gaudi 3 대안 칩**: OCI는 현재 NVIDIA 단일 의존. 대안 칩 파트너십 부재가 구조적 취약점

|-------|----------------|------------|-----------|---------|
| AWS (Amazon) | ~31% | $200B | Trainium2(자체) + NVIDIA | Capex 4배 우위. 자체 ASIC으로 원가 차별화 |
| Azure (Microsoft) | ~25% | $120B+ | NVIDIA 독점 + Maia(자체) | OpenAI API 생태계 선점. 개발자 커뮤니티 압도 |
| GCP (Google) | ~12% | $175~185B | TPU v5(자체) + NVIDIA | 자체 AI 연구 생태계. TPU 오픈화 위협 잠재 |

> 핵심 비대칭: Oracle $50B capex로 AWS $200B의 1/4에 불과하나, AI 특화 GPU 클러스터 집중으로 단위 효율 극대화. "규모 경쟁" 대신 "AI 전용 수탁 운영" 포지션.

### NVIDIA 칩 할당 격차 현황

- **OCI**: NVIDIA H100/H200/Blackwell 수십만 대 확보. Stargate 프로젝트(Texas Abilene) 중심으로 Blackwell GB200 대규모 배치 추진 중
- **AWS/Azure/GCP**: NVIDIA 물량 우선 배정 경쟁 + 자체 ASIC 병행으로 NVIDIA 의존도 분산
- **OCI 불리점**: NVIDIA 단일 의존이므로 칩 공급 차질(TSMC CoWoS 병목 등) 시 구축 일정 직접 타격
- **OCI 유리점**: Stargate 메가딜 규모(500B, 4년)가 NVIDIA와의 장기 공급 계약 협상력 제공

## ▶ 디스럽션 리스크 분석

### 핵심 디스럽션 시나리오 3가지

#### 시나리오 D1: OpenAI-Microsoft 관계 재편 — Stargate 흔들림 (중간 확률: 25~30%)

**배경**: OpenAI는 현재 Microsoft Azure(API 생태계, 독점 공급계약)와 Oracle OCI(물리 인프라, Stargate)를 동시에 활용하는 이중 구조다.

**위협 경로**:
- Microsoft가 OpenAI 지분 재협상·독점 조항 강화 시, OpenAI의 OCI 활용을 Azure로 흡수 압력
- OpenAI가 자체 인프라(자사 데이터센터 직접 구축) 전략 전환 시 Stargate 계약 규모 축소 가능
- OpenAI 경영 불안정(이사회 분쟁 재발) 시 Stargate 프로젝트 의사결정 지연

**Oracle 영향**: RPO $130B+ 중 Stargate 비중 50%+ 추정. 계약 축소 시 FY2027~FY2028 매출 예측 대폭 하향 조정 필요. 주가 -30%~-40% 충격 시나리오.

**대응 방어선**: Texas Abilene 물리 캠퍼스 착공·건설 진행 중이라 단기 계약 철회 물리적 어려움. Stargate 컨소시엄(SoftBank, MGX) 구조가 단일 당사자 이탈 제한.

---

#### 시나리오 D2: Meta Llama 오픈소스 + 자체 인프라 내재화 (중간 확률: 30~35%)

**배경**: Meta는 OCI의 AI 클라우드 고객이나, Llama 오픈소스 전략 + MTIA(자체 AI ASIC) 개발을 동시에 추진 중이다.

**위협 경로**:
- Meta MTIA 칩 성숙(FY2026~FY2027) + 자사 데이터센터 AI 클러스터 내재화 완성 시 OCI 의존도 급감
- Meta가 Llama를 통해 외부 개발자들의 자체 인프라 구축을 촉진하면, OCI 의존 AI 스타트업들도 자체 인프라로 이탈 가능
- 오픈소스 LLM 확산으로 클라우드 API 단가가 하락하면 OCI AI 인프라 매출의 단위 수익성 저하

**Oracle 영향**: Meta + ByteDance가 OCI 이탈 시 AI 클라우드 매출 $2~5B/년 손실 가능. 단, Stargate(OpenAI)와 별개 계약이라 직접 연동은 아님.

**대응 방어선**: Meta의 전체 AI 수요($60~65B capex/년)는 자체 인프라로 감당 불가. OCI는 오버플로우 수요와 특수 워크로드에서 지속 역할 가능.

---

#### 시나리오 D3: Google TPU 오픈화 + 생태계 확산 (낮은 확률: 15~20%)

**배경**: Google은 TPU v5를 Google Cloud(GCP) 전용으로 운영 중이나, 일부 TPU 접근성 확대 논의가 존재한다.

**위협 경로**:
- Google이 TPU를 오픈소스화하거나 GCP 외부 라이선스 제공 시, AI 학습 워크로드에서 NVIDIA 의존 OCI 대비 비용 우위 창출
- AI 개발자들이 TPU 기반 비용 최적화 솔루션으로 이동 시 OCI GPU 클러스터 수요 잠식
- GCP의 AI 추론 특화 서비스 강화(Gemini 인프라 개방) 시 OCI 가성비 포지션 희석

**Oracle 영향**: 단기 직접 영향 제한적(TPU 오픈화는 Google의 수익 모델과 충돌). 중장기적으로 AI 인프라 시장에서 NVIDIA GPU 중심 구조가 다원화되면 OCI의 NVIDIA 단일 의존 구조가 상대적 열위로 전환 가능.

**대응 방어선**: TPU는 Google 에코시스템에 종속된 특화 칩. 범용 엔터프라이즈 AI 워크로드에서 NVIDIA 호환성 요구로 OCI 전환 비용 여전히 높음.

## ▶ Porter's Five Forces 상세 근거

### 1. 기존 경쟁자 간 경쟁 (점수: 4/5 — 강)

**AI capex 전쟁이 역사상 최고 강도에 도달**: AWS $200B, GCP $175~185B, Azure $120B vs Oracle $50B. 규모 격차가 압도적이나, Oracle의 전략은 정면 대결 회피(AI 특화 틈새 + 가성비).

**Fusion Cloud vs SAP**: ERP 클라우드 전환 시장에서 SAP S/4HANA(클라우드 매출 ~$18B)와 Oracle Fusion(~$15B)이 직접 경쟁. SAP의 선점 우위이나 Oracle의 가격 경쟁력과 DB 연동 시너지로 점유율 경쟁 지속.

### 2. 신규 진입자 위협 (점수: 2/5 — 약)

**물리적 진입 장벽**: AI 데이터센터 구축 비용 $1T+. GPU 수십만 대 확보는 NVIDIA와의 장기 공급 계약 없이 불가. Stargate 같은 메가딜이 오히려 진입 장벽 역할.

**예외 위협**: 국가 주도 AI 인프라(중국 알리바바, 중동 G42 등)가 Sovereign AI 명분으로 특정 지역 시장 잠식 가능. 단, 글로벌 엔터프라이즈 시장에서는 여전히 제한적.

### 3. 대체재 위협 (점수: 3/5 — 중)

**DB 영역**: PostgreSQL(무료, 성능 개선 중)이 신규 프로젝트에서 Oracle 대체. 단, 미션크리티컬 OLTP는 20년+ 전환비용 해자로 보호. Databricks/Snowflake는 OLAP에 집중하여 직접 충돌 제한.

**AI 인프라 영역**: 오픈소스 AI 모델(Llama, Mistral) 확산이 AI API 수요를 분산시키나, 추론 인프라 수요는 오히려 증가(Jevons Paradox).

### 4. 공급자 교섭력 (점수: 4/5 — 강)

**NVIDIA 독점**: AI GPU 시장점유율 80~85%. OCI가 NVIDIA Blackwell 없이 AI 인프라 사업 불가. Stargate 규모($500B, 4년)가 어느 정도 협상력 제공하나, 구조적 종속 불변.

**TSMC 생산 제약**: Blackwell GB200 CoWoS 패키징 병목이 OCI AI 클러스터 구축 일정 직접 영향. 2026 Blackwell 출하 150~200만 유닛 목표 달성 여부가 OCI capex 집행 속도 결정.

### 5. 구매자 교섭력 (점수: 3/5 — 중)

**OpenAI 단일 고객 집중 위험**: RPO $130B+ 중 Stargate(OpenAI) 비중 50%+. OpenAI가 협상력을 행사할 경우 가격·조건 재협상 가능성. 계약 취소는 물리적 인프라 착공으로 제한되나 조건 변경은 위험.

**DB 고객 해자**: 포춘 500 90%+ 고객의 전환비용($50M~$1B+)이 구매자 교섭력을 구조적으로 억제. 장기 License Support 계약은 연 ~5~8% 인상을 고객이 사실상 수용.

## ▶ 사업 분석 핵심 시사점

### 산업 트렌드 관점 핵심 포인트 3가지

1. **AI capex 슈퍼사이클의 직접 수혜자 — 그러나 NVIDIA 의존이 구조적 취약점**
   빅테크 AI capex 합산 $660~690B(2026E)의 직접 수혜 구조. OCI가 AI 특화 GPU 클러스터에서 가성비 포지션 확립에 성공했으나, NVIDIA 단일 공급 의존(시장점유율 80~85%)은 AWS Trainium2/Google TPU 대비 원가 경쟁력 열위의 구조적 원인. AMD MI400, Intel Gaudi 3 파트너십 조기 확보가 중장기 경쟁력 방어에 필수.

2. **Sovereign AI가 OCI Dedicated Region의 구조적 성장 동인 — 과소평가된 기회**
   각국 정부의 AI 자주권 경쟁(중동·유럽·아시아)이 데이터 현지화 규제를 강화하면서, 기업 사내 전용 OCI 인프라를 제공하는 Dedicated Region 모델의 수요가 구조적으로 성장한다. 이 시장은 AWS/Azure/GCP의 중앙화 모델보다 Oracle의 분산·전용 모델이 본질적으로 적합하여, 전체 클라우드 시장 3위가 아닌 Sovereign AI 세그먼트 리더 포지션 가능.

3. **AI 추론(Inference) 시장 확대가 OCI 베어메탈 모델에 유리**
   학습(Training) 대비 추론(Inference) 비중이 60%+로 확대(2025)되고 지속 증가하는 트렌드는 OCI의 베어메탈 GPU 직접 제공 + 낮은 가격 구조와 맞물려 추론 서비스 사업자(AI API 기업, 엔터프라이즈 AI 앱)의 OCI 의존도를 높인다. 추론은 단위 비용이 핵심이므로 TCO 20~30% 우위가 실질적 고객 선택 결정 인자.

### 경쟁 포지션 관점 핵심 포인트 2가지

1. **DB 전환비용 해자(Strong) + AI 인프라 틈새(Moderate)의 복합 구조 — 양측에서 동시 락인 작동**
   Oracle의 경쟁 우위는 단일 해자가 아니다. 포춘 500 90%+ DB 락인(전환비용 $50M~$1B+, 20년 이상 지속 가능)이 기저 현금흐름을 보장하고, OCI AI 인프라 성장이 추가 수익층을 형성하는 이중 구조다. 멀티클라우드 전략(Oracle Database@Azure/AWS)은 두 해자를 클라우드 시대에 동시 연장하는 핵심 메커니즘이다.

2. **OpenAI 단일 고객 집중도 리스크 vs Stargate 선점 효과의 트레이드오프 — 분산화가 중장기 과제**
   RPO $130B+의 Stargate 집중 구조는 AI 인프라 선도자 지위를 확인하는 동시에, 단일 고객(OpenAI-SoftBank-MGX 컨소시엄) 계약 변동 시 현금흐름 예측 가능성이 급격히 훼손될 수 있다. xAI, Meta, ByteDance 등 추가 대형 AI 고객으로의 분산화가 진행되고 있으나, 분산 속도가 Stargate 의존도를 상쇄할 만큼 빠른지 확인이 필요하다. 분기별 RPO 잔액과 신규 수주 분포가 핵심 모니터링 지표.
