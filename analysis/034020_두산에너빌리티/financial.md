2. **수주 단가 상승**: 원전 르네상스로 협상력 강화
3. **가동률 향상**: 수주 증가 → 공장 가동률 상승 → 고정비 희석
4. **SMR 프리미엄**: SMR 기자재는 대형 원전 대비 마진 우위
