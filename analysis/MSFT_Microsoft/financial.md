## 4. 목표주가 산정 (Multi-Method Valuation)

### Method 1: 상대 밸류에이션

#### 피어그룹 선정
| 피어 | 선정 이유 | Forward PER | ROE |
|------|----------|-------------|-----|
| Apple (AAPL) | 대형 테크, 구독 전환 중 | 26x | 140%+ |
| Alphabet (GOOGL) | 클라우드+AI 경쟁사 | 20x | 28% |
| Amazon (AMZN) | AWS 직접 경쟁사 | 30x | 20% |
| Salesforce (CRM) | 기업용 SaaS 경쟁 | 25x | 10% |
| Oracle (ORCL) | 기업용 클라우드 경쟁 | 22x | 80%+ |

| 지표 | MSFT | 피어 평균 | 피어 중간값 | 프리미엄/디스카운트 |
|------|------|---------|-----------|-------------------|
| Forward PER (FY26E) | 27.1x | 24.6x | 25.0x | +8.4% 프리미엄 |
| PBR | 10.5x | 12.0x (왜곡) | 8.0x | +31.3% 프리미엄 |
| EV/EBITDA | 22.0x | 20.5x | 21.0x | +4.8% 프리미엄 |
| PSR | 11.3x | 8.0x | 7.5x | +50.7% 프리미엄 |

#### 적정 PER 산출
```
적정 PER = 피어 평균 PER(24.6x) x (MSFT ROE 37% / 피어 평균 ROE 55.6%)
         = 24.6x x 0.67 = 16.4x (ROE 왜곡 — Apple/Oracle 극단값 제외)

ROE 왜곡 보정 (Apple, Oracle 제외):
피어 평균 ROE (GOOGL 28%, AMZN 20%, CRM 10%) = 19.3%
적정 PER = 24.6x x (37% / 19.3%) = 24.6x x 1.92 = 47.2x (상한)

현실적 범위: 피어 중간값 25x ~ ROE 프리미엄 35x
보수적 적정 PER = 28x (AI 성장 프리미엄 + Wide Moat 감안)
```

#### 상대 밸류 목표주가
```
목표주가 = 적정 PER(28x) x Forward EPS($14.20) = $397.60
현재가 대비 +3.4%
```

### Method 2: DCF (Discounted Cash Flow)

#### 핵심 가정
| 가정 | 수치 | 근거 |
|------|------|------|
| 매출 성장률 Y1~Y3 | +15%, +14%, +13% | AI+클라우드 성장 반영 |
| 매출 성장률 Y4~Y5 | +12%, +10% | 성장 정상화 |
| 영업이익률 | 44% → 46% | CapEx 투자 효과 발현 |
| CapEx/매출 | 27% → 20% | 투자 사이클 정상화 |
| WACC | 8.5% | Rf 4.2% + Beta 1.1 x ERP 4.0% + Size 0% |
| Terminal Growth Rate | 3.5% | AI 시대 장기 성장 반영 |

#### DCF 산출
```
Year 1 FCF: $2,910억 x 15.5% (FCF 마진) = $451억
Year 2 FCF: $3,317억 x 18.0% = $597억
Year 3 FCF: $3,748억 x 21.0% = $787억
Year 4 FCF: $4,198억 x 23.0% = $965억
Year 5 FCF: $4,618억 x 25.0% = $1,155억

Terminal Value = $1,155억 x (1.035) / (0.085 - 0.035) = $23,900억

PV of FCFs (Y1~5) = $2,930억
PV of TV = $15,862억
Enterprise Value = $18,792억
- 순부채 = -$400억 (순현금 가산)
Equity Value = $19,192억 → $1.92T

적정 주가 = $1.92T / 74.3억주 = $258

주의: DCF는 CapEx 급증 구간에서 FCF가 크게 압축되어 보수적 결과.
FCF 마진이 FY2028 이후 정상화(25%+) 가정에 민감.
```

### Method 3: PER 밴드 (보조)
```
과거 5년 PER 밴드:
  최고: 38x (2021년 성장주 버블)
  평균: 32x
  최저: 24x (2022년 금리인상 저점)

현재 PER: 30.2x (TTM) → 평균 32x 부근
평균 PER 회귀 시 목표주가 = 32x x $12.75 (TTM EPS) = $408
Forward 기준: 32x x $14.20 = $454
```

## 5. 재무 분석 핵심 시사점

1. **수익성 최상위**: OPM 45%, ROE 37~38%, ROIC-WACC 스프레드 +19%p — 가치 창출 기업의 교과서
2. **CapEx 투자 사이클 진입**: FY2026 CapEx $800억으로 FCF 일시 압축. 이 투자가 FY2027~28에 Azure AI 매출로 회수되는지가 핵심 변수
3. **실적 퀄리티 양호**: 구독 매출 비중 65%, Cash Conversion 119%, 비경상 항목 미미
4. **밸류에이션 합리적**: Forward PER 27x는 과거 평균(32x) 대비 할인. AI 성장 프리미엄 감안 시 저평가 가능
5. **핵심 리스크**: CapEx ROI 지연 시 FCF Yield 1.6% → 1% 이하로 추락 가능
