### 목표주가 산정 (3가지 방법)

**① DCF (Discounted Cash Flow)**

가정:
- 할인율(WACC): 8.5%
- 영구성장률: 3.0%
- 5년 FCF 성장률: 2026 $13B → 2030E $28B (CAGR +21%)
- 5년 후 FCF: $28B, Terminal Value = $28B × (1.03 / (0.085-0.03)) = $524B
- Enterprise Value = $524B × 0.62(할인) + 5년 FCF 합산 PV $85B = $409B
- 순부채 $32.5B 차감 → Equity Value $376B... 이는 현재 시총보다 낮음

> **DCF 결과: $420/주** → 보수적. 터미널 구조가 GLP-1 독점 가치를 반영 못함.

**② 상대 밸류에이션 (Forward PER 기반)**

- 2027E EPS: $30.80
- 적정 Forward PER: 35배 (성장률 +20%, ROE 100%, Moat Wide 감안)
- 2027E 적정 주가 = $30.80 × 35 = **$1,078**
- 현재가 대비 +19.3%
