## 4. 목표주가 산정 (Multi-Method Valuation)

### Method 1: 상대 밸류에이션

#### 피어그룹 선정

| 기업 | 시가총액 | Forward PER | Forward PS | 매출 성장률 | OPM | 선정 이유 |
|------|---------|-------------|-----------|-----------|-----|----------|
| Snowflake (SNOW) | $55B | N/A(적자) | 15x | +25% | 적자 | 클라우드 데이터 플랫폼 |
| Datadog (DDOG) | $40B | 70x | 15x | +24% | 25% | SaaS 옵저버빌리티 |
| CrowdStrike (CRWD) | $85B | 75x | 20x | +28% | 22% | 보안 SaaS + 정부 |
| ServiceNow (NOW) | $200B | 55x | 18x | +22% | 30% | 엔터프라이즈 AI SaaS |
| MongoDB (MDB) | $25B | 50x | 14x | +18% | 15% | 데이터 플랫폼 |

| 항목 | PLTR | 피어 평균 | 피어 중간값 | 프리미엄 |
|------|------|----------|-----------|---------|
| Forward PER | 170x | 62.5x | 62.5x | +172% |
| Forward PS | 57x | 16.4x | 15x | +280% |
| PEG | 4.5x | 2.5x | 2.3x | +96% |
| 매출 성장률 | +41% | +23% | +24% | +74% |
| OPM | 26% | 23% | 23% | +13% |
| ROE | 24% | 15% | 18% | +33% |

#### 적정 PER 산출
- 피어 평균 PER: 62.5x
- 성장 프리미엄: PLTR 성장률(41%) / 피어 평균(23%) = 1.78x
- ROE 프리미엄: PLTR ROE(24%) / 피어 평균(15%) = 1.60x
- AI 플랫폼 프리미엄: 1.3x (정부 AI 독점 + AIP 모멘텀)
- 적정 PER = 62.5 x 1.78 x 1.3 = **145x** (성장 프리미엄 + AI 프리미엄)
- 다만 ROE 프리미엄을 동시 적용하면 과대 -> 성장 프리미엄만 적용
- 보수적 적정 PER = 62.5 x 1.5 = **94x** (보수적 프리미엄)

#### 상대 밸류에이션 목표주가
- Forward EPS(FY2026E): $0.77
- 적정 PER 94x 적용: $0.77 x 94 = **$72.4**
- 적정 PER 145x 적용: $0.77 x 145 = **$111.7**
- **상대밸류 목표주가 범위: $72~$112**

| WACC | 10.0% | Rf 4.5% + Beta 1.5 x ERP 5.5% - 대형주 조정 -2.75% |
| Terminal Growth | 3.5% | AI 산업 장기 성장률 |

#### FCF 추정

| 연도 | 매출 | FCF Margin | FCF | PV(FCF) |
|------|------|-----------|-----|---------|
| Y1 (2026) | $5.37B | 31% | $1.66B | $1.51B |
| Y2 (2027) | $7.09B | 32% | $2.27B | $1.88B |

| Y4 (2029) | $10.90B | 34% | $3.71B | $2.53B |
| Y5 (2030) | $12.86B | 35% | $4.50B | $2.79B |
| Terminal Value | — | — | $71.7B | $44.5B |
| **합계** | | | | **$55.4B** |

- TV = FCF(Y5) x (1+g) / (WACC - g) = 4.50 x 1.035 / (0.10 - 0.035) = $71.7B
- 기업가치(EV): $55.4B
- (-) 순현금: -(-$3.6B) = +$3.6B
- 적정 시가총액: $59.0B
- 발행주식수: 23.9억 주
- **DCF 적정주가: $24.7** (현재가 $132.37 대비 -81%)

> DCF는 극단적으로 낮은 결과. 이는 WACC 10%와 Terminal Growth 3.5% 가정이 현재 시장이 부여하는 초프리미엄을 전혀 반영하지 못하기 때문.
> DCF로는 현재 주가를 정당화하려면 WACC 6% + Terminal Growth 5%+ 수준이 필요 -> 비현실적.

## 5. 재무 분석 핵심 시사점

1. **영업레버리지 확인**: OPM이 5.4% -> 19.8%로 3년간 14.4%p 개선. 매출 성장이 곧 이익 폭발로 직결되는 구조. SBC 비중 감소 추세도 긍정적.

2. **FCF vs 밸류에이션 괴리**: FCF Margin 32%는 최상위 SaaS 수준이나, FCF Yield 0.4%는 극히 낮음. $1.25B FCF로 $316B 시총을 지탱하려면 수년간 고성장 필수.

3. **밸류에이션이 최대 리스크**: Forward PER 170x+는 동종업계 평균 62x의 2.7배. 성장률 프리미엄을 감안해도 과도. 성장 둔화 시 멀티플 수축(derating)으로 주가 급락 가능성 높음. Base Case 적정가 $85 기준 현재가는 55% 고평가.
