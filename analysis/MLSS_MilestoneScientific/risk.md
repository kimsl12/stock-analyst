## 2. 핵심 리스크 심층 분석

### R1. 현금 고갈 → 유상증자 (최우선 리스크)

**현황 팩트**:
- 2025년말 현금 $1.11M, 연간 FCF -$2.93M
- 2026년 Q1 기준 예상 현금 잔고: $400K 내외
- 분기당 현금 소진 $730K → **2026년 Q2 이전에 자본조달 필수**

**유상증자 시나리오**:
- 최소 필요 자금: $5M (1~2년 운영)
- 현재 시총 $23.5M 대비 $5M = **약 21% 희석**
- 할인율 20~30% 반영 시 신주 발행가 $0.20~0.23
- 주식수 80M → 105M (**+31% 증가**)
- 예상 목표가 하향: -20~-30%

**Devil's Advocate 최악 시나리오**:
- 유상증자 흥행 실패 → $10M 조달 필요 → 50%+ 희석
- 주당 가치 $0.15 수준으로 하락

### R2. NYSE American 상장폐지 리스크

**상장 규정 (NYSE American Continued Listing Standards)**:
- 최저 주가 요구치 없음(기술적으로), 그러나 $0.20 이하 장기 유지 시 실질적 상장폐지 심사 대상
- 주주자본 최소 $4M 요구 → MLSS 현재 $2.8M으로 **이미 위반 상태**

**시나리오**:
- NYSE American 상장폐지 경고 → 6개월 이내 해결 요구
- 해결 실패 시 → **OTC 마켓 이동** (유동성 급감, 기관 투자 원천 차단)
- OTC 이전 시 주가 추가 -30~-50% 하락 전례 많음

### R3. 매출 감소 (수익성 더 악화)

**2025 Q4 매출 QoQ -13%**는 일시적일 수 있으나, 만약 2026년 이어지면:
- 매출 $7~8M 수준 → 영업손실 확대
- 추가 자본조달 반복 → **데스 스파이럴(Death Spiral)**

## 3. Devil's Advocate: Bull Case 반박

### Bull 주장 1: "바닥권이니 반등 가능"
**반박**:
- 지난 10년간 MLSS는 여러 번 "바닥"이었다. 그때마다 추가 하락했다.
- 주가 $4 (2018년) → $1 (2020년) → $0.29 (현재). 각 시점마다 "저평가"라고 주장되었다.
- **적자 지속 기업의 '바닥'은 존재하지 않는다** — 0에 수렴하거나 상장폐지될 때까지 하락 가능.

### Bull 주장 2: "M&A 대상 가능성"
**반박**:
- 10년간 M&A 소문은 있었으나 실제 성사 없음
- Dentsply Sirona는 자체 경쟁 제품 보유, MLSS 인수 동기 약함
- 특허 포트폴리오가 매력적이라면, 이미 10년 전에 M&A 되었을 것
- **기다림의 기회비용** 무시 불가

### Bull 주장 3: "매출총이익률 71%는 우수"
**반박**:
- 71% GPM은 **절대 금액으로 환산하면 $6.4M**에 불과 (SG&A $11.6M 커버 불가)
- 고수익률도 "규모 없는 고수익"은 의미 없음
- 실제 경제적 가치(Economic Profit) = 매출총이익 - SG&A - R&D = **-$5.6M**

### Bull 주장 4: "CompuFlo 중국 진출 촉매"
**반박**:
- 중국 규제 환경 악화 + 미중 긴장 속에서 중국 의료기기 진출 **매우 어려움**
- 중국 현지 제조사가 유사 제품 개발 후 가격 경쟁 시 MLSS 패배
- 2020년부터 중국 진출 언급, 5년간 매출 기여 미미

### Bull 주장 5: "내부자 22% 보유"
**반박**:
- 내부자가 매도하지 않는 이유가 **"매도 불가"**일 수도 있음 (블록 매도 시 주가 즉시 붕괴)
- 내부자 보유는 락인(lock-in)의 결과일 뿐, 의지의 증거 아님

## 4. 스트레스 테스트

### 시나리오 A: 금리 상승 지속
- 자본조달 비용 증가 → MLSS 부채 발행 어려움
- 유상증자 시 할인율 확대 → 더 많은 희석
- **영향: 주가 추가 -20~-30%**

### 시나리오 B: 경기침체
- 선택적 의료 지출(치과) 감소
- 치과의사 장비 투자 연기 → MLSS 매출 -15~-20%
- **영향: 주가 -30~-40%**

### 시나리오 C: 미중 관세 재격화
- CompuFlo 중국 진출 차질
- 중국 공급망 의존 부품 비용 상승
- **영향: 성장 동력 상실, -20%**

## 5. 리스크 억제(Risk Mitigation) 관점

**어떤 경우 이 리스크가 해소되는가?**
1. 흑자 분기 실현 (매출 $4M 분기 달성 시) → 현재 분기당 $2M 수준, **2배 성장 필요**
2. 전략적 M&A 제안 수령 → 불확실
3. 전환사채가 아닌 지분 희석 없는 자본 확충(예: 라이선싱 딜, 로열티) → 가능하나 전례 없음
