**"단위 경제(Unit Economics)는 좋은데 규모의 경제를 못 만듦"**
- 71% 매출총이익 → 장비·소모품 수익성은 건강
- 그러나 SG&A $11.6M (매출의 129%) → 판매·관리비 절대 규모가 매출을 초과
- 흑자 전환 조건: 매출 $16M+ 도달 필요 (현재 대비 +78%)
- 현재 성장률 YoY +4%로는 **흑자 전환까지 10년+ 소요**

## 7. 목표주가 산정 (시나리오 분석)

MLSS는 적자기업이라 DCF나 PER 기반 산정이 곤란하므로, **P/S 기반 상대밸류 + 시나리오** 방식 사용.

### Base Case (45% 확률): 현재 추세 지속
- 2026E 매출 $9.5M (+6% YoY)
- 영업손실 $4.5M → 유상증자 시 20~30% 희석
- P/S 2.0배 적용 (희석 후 주식수 105M 기준)
- **목표가 $0.18** (-38%)

### Bull Case (25% 확률): 턴어라운드 성공
- 매출 $12M+ 달성, 영업손실 절반 축소 ($2.5M)
- CompuFlo 중국 판매 본격화 + 비용 구조 추가 개선
- P/S 4.0배 (업종 평균) 적용
- **목표가 $0.60** (+107%)

### Bear Case (30% 확률): 상장폐지 또는 심각한 희석
- 현금 고갈 → 대규모 유상증자 (50%+ 희석) 또는 NYSE American 상장폐지 → OTC로 이동
- **목표가 $0.10** (-66%)

### 기대값 가중평균
- $0.18 × 0.45 + $0.60 × 0.25 + $0.10 × 0.30 = $0.081 + $0.150 + $0.030 = **$0.26**
- **가중 목표가: $0.26** (현재 $0.29 대비 **-10%**)
