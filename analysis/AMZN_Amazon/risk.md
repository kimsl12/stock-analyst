## 2. 리스크 상세 분석

### 리스크 #1: AI CapEx ROI 불확실성 [등급: 높음]

**Devil's Advocate 관점:**
"아마존은 2025년에 CapEx $131.8B를 투입하고 FCF는 겨우 $7.7B. 이 중 AWS AI 인프라에 $80B+를 쏟아붓고 있는데, AI 서비스에서 이에 상응하는 수익이 실제로 나오고 있는가? Bedrock과 SageMaker가 Azure OpenAI를 이길 수 있는 차별점이 있는가?"

**핵심 우려:**
- CapEx $131.8B vs FCF $7.7B → 투자 대비 수익 비율 극히 낮음
- AI 모델 학습 비용 하락(DeepSeek 효과) 시 인프라 과잉투자 위험
- Trainium 칩의 실제 성능/채택률이 NVIDIA GPU 대비 검증 미흡
- AI 서비스 수익화까지 18~24개월 시차 존재

**완화 요인:**
- 하이퍼스케일러 전체가 동시 투자 중 → 아마존만의 리스크 아님
- AWS 자체 칩(Trainium)은 장기적으로 NVIDIA 의존도 낮춤 → 원가 절감
- Anthropic 독점 파트너십 → Bedrock 차별화 자산
- CapEx의 일부는 감가상각으로 장기 분산

**모니터링 지표:** AWS AI 서비스 매출 성장률, Bedrock 고객 수, Trainium 채택률

---

### 리스크 #2: AWS 경쟁 심화 [등급: 높음]

**Devil's Advocate 관점:**
"AWS 점유율이 2020년 34%에서 2025년 31%로 3%p 하락했다. Azure는 OpenAI를 독점하고 Enterprise 시장에서 M365+Azure 번들로 승부한다. GCP는 Gemini+TPU로 AI 차별화에 성공하고 있다. AWS의 AI 전략(Bedrock + 다양한 LLM)이 OpenAI 독점 Azure를 이길 수 있는가?"

**핵심 우려:**
- Azure의 OpenAI 독점 → Enterprise AI 도입 시 Azure 선호 강화
- AWS 점유율 지속 하락 시 '2등 클라우드' 이미지 리스크
- GCP의 Gemini+TPU 생태계가 특정 워크로드에서 AWS 대체 가능

**완화 요인:**
- 점유율은 하락하나 절대 매출은 20%+ 성장 → 시장 자체가 확대
- AWS는 멀티LLM 전략(Bedrock)으로 벤더 락인 최소화 → 기업 선호
- Anthropic Claude의 코딩/분석 영역 강점 → Bedrock 차별화
- 기존 AWS 고객의 전환 비용이 높아 이탈률 낮음 (연 5% 미만)

**모니터링 지표:** AWS vs Azure 성장률 격차, Bedrock 신규 고객 수, 엔터프라이즈 AI 계약

### 리스크 #3: 관세 & 무역 분쟁 [등급: 높음]

**Devil's Advocate 관점:**
"트럼프 행정부의 대중 관세 145%는 아마존 3P 셀러의 60%+가 중국산 제품을 판매하는 구조에 직격탄이다. 제품 가격 상승 → 소비 위축 → 거래액(GMV) 감소 → 광고 매출도 타격. 이 악순환을 어떻게 막을 것인가?"

**핵심 우려:**
- 3P 셀러 중 중국 셀러 비중 40~50% → 관세 직접 영향
- 소비자 가격 상승 → Prime 회원 이탈 가능성
- 관세 불확실성 → 3P 셀러 재고 조정 → GMV 둔화

**완화 요인:**
- 아마존은 마켓플레이스 모델 → 관세 비용은 셀러/소비자가 부담
- 미국 내 1P 상품 비중 확대로 중국 의존도 축소 가능
- 관세 면제/완화 협상 가능성 (특히 전자제품 카테고리)
- 소비자가 가격 인상 후에도 아마존 내에서 쇼핑 → 점유율 유지

**모니터링 지표:** 3P 셀러 이탈률, GMV 성장률, 관세 정책 변화

### 리스크 #4: 반독점 규제 (FTC 소송) [등급: 중간~높음]

**핵심 우려:**
- FTC vs Amazon 소송 (2023년 제기) → 마켓플레이스 독점 행위 혐의
- 최악 시나리오: 마켓플레이스 분리 명령 → 기업 가치 훼손
- 현실적 시나리오: 벌금 + 행위 제한 명령 → 비즈니스 관행 변경 요구

**완화 요인:**
- 트럼프 행정부는 빅테크 규제 완화 기조
- FTC 위원장 교체 가능성 → 소송 약화/취하
- 기업 분리 명령은 역사적으로 매우 드문 결과

### 리스크 #5: FCF 압박 [등급: 중간]

**핵심 우려:**
- 2025년 FCF $7.7B (FCF Yield 0.3%) → 성장 투자에 올인
- CapEx 증가 추세 지속 시 주주 환원 능력 제한
- 금리 상승 환경에서 차입 비용 증가 가능

**완화 요인:**
- 영업현금흐름 $139.5B는 매우 건강 → CapEx 감축 시 FCF 급반등
- CapEx는 성장 투자이지 구조적 비용 아님 → 투자 주기 종료 시 정상화
- 이자보상비율 35x → 재무 건전성 양호

## 3. 시나리오 분석

### Bull Case (확률 25%)
- AWS AI 수익화 가속 → AWS 성장률 25%+
- 이커머스 마진 13%+ 달성
- 관세 완화, 경기 연착륙
- **목표주가: $320~$360**

### Base Case (확률 50%)
- AWS 20% 성장 유지, 마진 개선 지속
- 관세 영향 제한적, EPS $9.38 달성
- **목표주가: $260~$290**

### Bear Case (확률 25%)
- AWS 성장 15%로 둔화, AI CapEx ROI 의문
- 관세 심화 + 경기 침체
- EPS $7.5~$8.0으로 하향
- **목표주가: $180~$210**

## 4. Devil's Advocate 종합 의견

**"아마존의 가장 큰 리스크는 AI 투자의 ROI 불확실성이다."**

CapEx $131.8B를 투입하면서 FCF가 $7.7B로 급감한 상황은, AI 인프라 투자가 실제 수익으로 전환되지 않으면 주가에 심각한 하방 압력을 줄 수 있다. Azure+OpenAI 조합이 Enterprise AI 시장을 장악하고, AWS의 Bedrock+Anthropic이 차별화에 실패하면, 아마존은 "이커머스 회사가 클라우드에서 밀리는" 최악의 내러티브에 직면할 수 있다.

다만, 이는 아마존만의 리스크가 아니라 하이퍼스케일러 전체의 구조적 리스크이며, 아마존의 다각화된 사업 포트폴리오(이커머스+광고+AWS)는 어느 한 사업부의 부진을 다른 사업부가 상쇄할 수 있는 버퍼를 제공한다.

**리스크 대비 보상비율 (Risk/Reward): 양호**
- 현재가 $240에서 Bear Case $190 → -21% 하방
- 현재가 $240에서 Bull Case $340 → +42% 상방
- 상방/하방 비율: 2:1 → 투자 매력적
