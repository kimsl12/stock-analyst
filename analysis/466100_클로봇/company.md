## 1. 기업 정체성 요약

클로봇(Clobot)은 2017년 설립된 **서비스로봇 자율주행 소프트웨어 전문 기업**으로,
하드웨어를 제조하지 않고 **"로봇의 두뇌(Brain)"에 해당하는 SW 플랫폼만 공급**하는 Pure SW 플레이어다.
2024년 10월 KOSDAQ 상장(공모가 15,000원), 현재 시가총액 약 1.24조원.

핵심 제품은 **Cloi 자율주행 플랫폼**으로 LG전자의 서비스로봇(클로이 시리즈) 전량에 SW를 공급하는
독점적 파트너이자, 자체 솔루션으로 공항·대형마트·병원·물류센터에 AMR/AGV를 납품한다.

## 2. 사업 모델 (Business Model)

```
┌─────────────────────────────────────────────────┐
│  클로봇 Cloi 플랫폼 (SW)                        │
│    ├─ SLAM/Localization Engine                  │
│    ├─ Navigation & Path Planning                │
│    ├─ Multi-Robot Orchestration                 │
│    ├─ Cloud Management (SaaS)                   │
│    └─ AI 객체인식/대화 모듈                     │
├─────────────────────────────────────────────────┤
│  수익 구조                                      │
│    1. SW 라이선스 (55%) — LG전자 등 HW 제조사  │
│    2. 턴키 솔루션 (25%) — AMR + SW 결합 공급   │
│    3. SaaS/유지보수 (12%) — 리커링             │
│    4. 연구용역 (8%) — 정부 과제               │
└─────────────────────────────────────────────────┘
```

**SW+SaaS 매출 비중 약 67%** → 제조업이 아닌 **소프트웨어 기업**으로 분류됨.
이는 고마진 구조(장기적 OPM 20%+ 가능) 및 **"애플리케이션이 늘수록 한계비용이 0에 수렴"**하는
소프트웨어 네트워크 효과를 기대할 수 있는 구조.

## 3. 경쟁적 해자(Moat) 분석 — 5가지 원천

### 3-1. 무형자산(Intangible Assets) — Narrow Moat
- **LG전자와의 독점 파트너십**: 2018년 공동 연구로 시작, 2024년 배타적 SW 공급권 확보
- **Cloi 브랜드 인지도**: LG전자 유통 네트워크를 등에 업고 국내 서비스로봇 SW 표준으로 인식
- **특허 포트폴리오**: 자율주행·멀티로봇 제어 관련 등록특허 80건 + 출원 140건 (2025 말)

### 3-2. 전환비용(Switching Costs) — Wide Moat 후보
- 고객사(마트, 공항)가 일단 Cloi 플랫폼에 연동되면 HW 교체 시에도 SW는 그대로 유지
- 기업 ERP, 물류시스템(WMS)과 통합된 맵 데이터·로그가 누적되어 **교체비용이 매우 높음**
- 특히 대규모 사업장(1,000평 이상)에서는 교체 시 6~12개월 재학습 필요 → **사실상 록인**

### 3-3. 네트워크 효과(Network Effect) — Narrow Moat 초기
- Cloi 사용 로봇이 늘수록 **공유 맵 데이터베이스**가 풍부해져 타사 대비 정밀도 우위
- 단, 아직 글로벌 규모는 아님 — NVIDIA Isaac, AWS RoboMaker 대비 상대적 열세

### 3-4. 비용우위(Cost Advantage) — No Moat
- SW 기업이므로 원가 우위 개념이 약함
- 다만 한국 내 인건비가 실리콘밸리 대비 낮아 **R&D Cost Leadership** 존재 (엔지니어 연봉 미국의 35~45%)

### 3-5. 규모의 경제(Efficient Scale) — 해당 없음
- 현재 시장 초기 단계라 규모 방어보다는 점유율 확대 경쟁기

## 4. 종합 Moat 평가

| 항목 | 평가 | 근거 |
|------|------|------|
| **Moat 등급** | **Narrow (이행 중: Narrow → Wide 가능)** | 전환비용 + LG전자 독점 파트너십 |
| **지속 가능성** | 5~7년 (단기) | LG전자 의존도·글로벌 경쟁사 진입 변수 |
| **Moat 방향성** | **Widening (확장 중)** | NVIDIA Isaac 제휴, 해외 진출 |

**핵심 리스크:** LG전자 매출 비중 55%로 지나치게 높음. LG전자가 경쟁사(예: NVIDIA·Siemens)와 추가 파트너십을 체결하거나 자체 SW 개발로 선회 시 Moat가 한순간에 붕괴.
**핵심 기회:** NVIDIA Isaac 파트너 선정(2026-03)을 계기로 글로벌 표준 SW 생태계 편입 시 Moat가 Wide로 격상 가능.

## 8. 투자 관점 종합 의견

클로봇은 **"소프트웨어 중심"의 드문 서비스로봇 Pure-Play 기업**으로,
Physical AI 시대의 최대 수혜주 중 하나로 분류될 수 있다.
단, 현 단계 밸류에이션(PSR 35배)은 이미 많은 프리미엄을 선반영했고,
Moat가 현재 Narrow 수준이므로 Wide로의 격상 증거(글로벌 수주·흑자 전환)가
실적으로 확인되기 전까지는 **"선택적 분할 매수" 관점이 합리적**.

**기업 등급: B+ (성장성 매우 높음, 방어력은 중간)**
