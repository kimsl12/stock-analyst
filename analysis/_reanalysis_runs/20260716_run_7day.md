### 1. timeline.json `target_price` 오염 — **기존 데이터 이미 손상**

`web/scripts/lib/scorecard_parser.mjs` 의 `parseTargetPrice()` 패턴 순서 결함. 일반 `목표가 …| $숫자` 표 행 패턴이 명시적 `**목표주가: $X**` 선언보다 **앞**에 있어, ATR 단기목표·Bear 시나리오 값을 12개월 목표가로 오기록.

| 종목    | timeline 기록 | 본문 실제   | 집어간 값     |
| ------- | ------------- | ----------- | ------------- |
| MRVL v9 | `$312.11`     | **$250**    | 3ATR 단기목표 |
| DIA v9  | `$488`        | **$544.50** | Bear 시나리오 |
| ETN v7  | `$340`        | **$440**    | Bear 시나리오 |

01:00 런(NEE·CCJ 등)이 정상이었던 건 ATR 행을 `단기 목표` 로 라벨링해 **우연히** 패턴을 피한 덕. 즉 **값의 정확도가 에이전트의 표기 습관에 의존**한다.

**본 회차 조치**: ① 위 변화표는 본문 실측값으로 수기 작성 ② 커밋 전 자체 10종의 ATR 행 라벨을 `단기 목표` 로 정규화 → 신규 10건 오염 차단 (정규화 후 9/10 정확, 검증 완료). **과거 데이터는 손대지 않음** — 파서 수정 + 전수 소급 백필은 별도 작업으로 분리.

**추출기가 3벌이고 각자 다르게 틀린다** — 본 회차에서 세 번째 결함도 확인:

| 추출기                                     | 증상                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| `lib/scorecard_parser.mjs`                 | 패턴 순서 결함 (위 표) + `n>1` 가드가 페니스톡 목표가 배제                           |
| `cleanup_reanalysis.mjs` 자체 폴백 (197행) | `→\s*` 대안이 **반증 조건을 결론으로 오캡처**                                        |
| `build_bootstrap.mjs` (66·69행)            | 등급 enum 에 `보유` 누락 + 폴백이 문서 내 첫 `**매도**` 무차별 캡처 + TP·날짜 오추출 |

`build_bootstrap` 실측 오류 (교정 전): SO `TP $85`(→$92, CI 하단) · ETN `TP $360`(→$440, Bear) · MLSS `TP $0.12`+날짜 `07-15`(→$0.22, `07-16`) · VMC **등급 누락**(→보유) · OKLO `매도`(→비중축소).

**OKLO 오캡처는 2026-07-03 LIN·SPGI·LNG 6종 사고의 재발**이다 (`cleanup_reanalysis.mjs` 31행 주석이 경고한 바로 그 패턴). 당시 패치가 `→` 대안을 남겨둬 불완전했다:

```

14행 (실제 결론): "**투자 등급: 비중축소 (Reduce) — 신규 진입 비권장**"
```

**본 회차 수기 교정**: timeline OKLO grade `매도`→`비중축소` · bootstrap 5행(SO·ETN·MLSS·VMC·OKLO). ⚠️ `build_bootstrap --apply` 재실행 시 되돌아갈 수 있음 — 근본 수정 후 재생성 권장.

**잔여 한계 2건**:

- `OKLO` 등급 `비중축소` 를 **3개 추출기 전부 처리 못 함** — `parseGrade()` 는 어휘 부재로 null, cleanup 폴백과 build_bootstrap 폴백은 하방 시나리오의 `매도` 를 오캡처. **"매도"로 확정하지 않고 `비중축소` 로 수기 교정했다** — 해당 분석은 35~49=비중축소 / <35=매도 를 명시 구분하고 "48점 = 비중축소 밴드 상단, 중립(50)까지 2점"이라고 썼다. `매도` 로 두면 분석이 지지하지 않는 강한 매도 신호로 왜곡된다. (timeline 에 이미 `null` 64건·비표준값 `D` 1건이 있어 어휘 확장이 스키마를 깨지 않음을 확인.)
- `parseTargetPrice()` 에 `n > 1` 가드가 있어 **페니 스톡 목표가($0.22) 구조적 거부**. MLSS 는 cleanup 자체 폴백(`tpPatterns[3]`, 가드 없음)이 받아내 timeline 은 정상 기록됨.
