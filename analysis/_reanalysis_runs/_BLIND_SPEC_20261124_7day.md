## 3. 타입 함정 (render 크래시 방지 — 반드시 준수)

- `current_price`, `target_price`, `low52`, `high52`, `atr`, `stop_loss` → **숫자**(문자열·쉼표 금지). 한국주도 `177500` (×, "₩177,500" 아님). 쉼표/통화기호는 render 가 붙임.
- `score` → 0~100 정수 / `scorecard_items` 점수 → **0~10**.
- `thesis` → **dict** (문자열 아님) / `extra_kpis` → [라벨,값] 쌍 리스트 / `custom_sections[].content` (키는 `content`, `body` 아님).
- 숫자 없으면 `null` (문자열 "N/A" 금지).

## 4. 데이터 위생

- data.json `artifact_notes` 를 먼저 읽고 반영하라(배당/52주/비용률/KR lag 플래그).
- yfinance 값이 상식과 크게 어긋나면(예: 삼성전자 배당 10%) 공개 지식으로 교차검증해 보정하고 artifact_notes 에 사유 남겨라. 보정 불가 시 보수적으로(낮은 confidence) 처리.
- ATR·손절선: data.json `quote.atr_14`, `quote.stop_loss_2atr` 사용. nan/음수면 재계산 또는 null.
