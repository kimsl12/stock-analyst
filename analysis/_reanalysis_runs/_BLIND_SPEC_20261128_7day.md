```
# {종목명} ({티커}) — 재분석 v{N} BLIND 스코어카드

**분석일: 2026-11-28 · 현재가 {통화}{현재가} (11-27 종가) · 섹터: {섹터}**

## 1. 종합 판단 (산문)
{4~6문단: 사업/해자, 밸류, 실적/재무, 모멘텀/기술, 매크로 적합성, 결론}

## 2. 10항목 가중 스코어카드
| 항목 | 점수(0~10) | 가중치 | 가중점수 | 근거 |
| --- | --- | --- | --- | --- |
{10행}

**종합 점수: {N} / 100**

**투자등급: {강력매수|매수|중립|매도|강력매도}**
```

> ⚠️ 점수 라인은 반드시 `**종합 점수: {숫자} / 100**` (숫자가 "종합 점수:" 직후 + "/ 100"). 합산식(a+b+...=X) 금지 — 파서 null 유발.
> ⚠️ 목표가는 `- **목표주가: {통화}{숫자}**` 형식(자유형·"기본 목표가" 금지 — 파서 null 유발).
> ⚠️ 비표준 등급어 금지(강력매수/매수/중립/매도/강력매도 enum만). ETF 레버리지성이면 "매도"로.

### (B) `_report_data.json` — HTML 렌더 소스. 아래 키 **전부** 채운다(값은 data.json 실측 + 분석):

```json
{
  "ticker": "{티커}",
  "name": "{종목명}({티커}) — 재분석 v{N} (이전 비교 미포함)",
  "date": "2026-11-28",
  "asset_type": "주식",   // ETF면 "ETF"
  "currency": "$",        // ADR·미국상장 전부 "$"
  "score": 57,            // 정수 0~100 (scorecard 종합점수와 일치)
  "grade": "중립",         // enum
  "current_price": 63.32, // 숫자(문자열 금지)
  "market_cap": "$27.6B", // 문자열 표기 OK
  "per": "trailing 95.9 / fwd 37.8",
  "low52": 56.75, "high52": 135.24,   // 숫자
  "atr": 3.53, "stop_loss": 56.25, "target_price": 80,  // 숫자
  "scorecard_items": [["경제적 해자", 8], ...10개...],   // [이름,점수0~10] pair. ETF는 ETF항목명.
  "extra_kpis": [["배당수익률","0.27%"], ...],           // [라벨,값] pair
  "executive_summary": "...", "company_overview": "...",
  "moat_rating": "넓음(Wide)", "moat_details": "...",
  "financial_analysis": "...", "valuation": "...", "momentum": "...",
  "business_analysis": "...", "risk_summary": "...", "strategy": "...",
  "risks": [{"name":"...","level":"높음","impact":"...","desc":"..."}, ...4~5개],
  "thesis": {"claim":"...","support":"...","falsifier":"..."},   // 반드시 dict(문자열 금지)
  "custom_sections": [
    {"title":"§ Confidence Interval","content":"Bear:... Base:... Bull:..."},
    {"title":"§ 약한 가정 3개 (Most Fragile Assumptions)","content":"1.... 2.... 3...."}
  ],
  "artifact_notes": []
}
```

- ETF면 scorecard_items를 ETF 항목으로(예: "경제적 해자(지수 구성·구조적 우위)","밸류에이션","재무 건전성","성장성","모멘텀·기술","매크로 적합성","유동성·수급","리스크(베타·하방)","비용·추적 효율(보수율·NAV)","분산·구성"). company_overview→지수/구성 설명, moat_rating→"해당없음(패시브)" 또는 지수 구조 우위.
- 가격 필드(current_price·low52·high52·atr·stop_loss·target_price)는 **반드시 숫자**(문자열 금지 — render 크래시).
- ATR·손절가: data.json의 atr_14·stop_loss_2atr 활용(손절 = 현재가 - 2×ATR 기준, 단 52주 저점권·지지선 고려해 조정 가능).
