# BLIND 재분석 작업 명세 (2026-06-16)

너는 자동 스케줄 런의 일부로, 지정된 1개 종목의 **BLIND v{N} 재분석**을 처음부터 끝까지 직접 수행한다.
오늘 날짜는 **2026-06-16**. 프로젝트 루트(ROOT):
`/Volumes/외장SSD/클로드 AI 폴더/작업폴더/종목분석 에이전트`

너에게는 Read/Write/Bash/Grep/Glob 도구가 있다. **모든 단계를 직접 인라인으로 수행하라.**
"서브에이전트/도구 부재"를 사유로 중단·SKIP 하지 마라 — 필요한 도구는 전부 갖췄다.

## 🔴 BLIND 제약 (앵커링 차단) — 최우선

- 다음을 **절대 Read 하지 마라**: `analysis/{폴더}_v{N-1}/` 및 그 이하 옛 버전, `reports/{티커}_*.html`, `analysis/_history/*_timeline.json`.
- 이전 스코어/등급/목표가를 보지 말고, **현재 데이터 + KB + 너의 지식**만으로 독립 결론을 내려라.
- "이전엔 X였으나" 같은 비교 문장 금지 (너는 이전을 모른다).

## STEP 1 — 최신 데이터 수집

```bash
cd "ROOT" && python3 scripts/fetch_price.py {티커}
```

출력 JSON에서 current_price, prev_close, change_pct, high_52w, low_52w, market_cap, market_cap_str,
volume, atr_14, atr_pct, stop_loss_2atr, target_3atr, date 를 추출한다.

출력 폴더 `analysis/{폴더}_v{N}/` 를 만들고 `data.json` 을 아래 스키마로 작성:

```json
{
  "metadata": {
    "ticker": "{티커}", "company_name": "{영문명}", "company_name_ko": "{한글명}",
    "analysis_date": "2026-06-16", "analysis_version": "v{N}", "analysis_mode": "BLIND_reanalysis",
    "asset_type": "주식", "sector": "{섹터}", "currency": "{$ 또는 ₩}", "prev_version_date": "2026-06-07"
  },
  "currency": "...", "date": "...", "current_price": ..., "prev_close": ..., "change_pct": ...,
  "high_52w": ..., "low_52w": ..., "market_cap": ..., "volume": ..., "atr_14": ..., "atr_pct": ...,
  "stop_loss_2atr": ..., "target_3atr": ..., "fetch_time": "...", "market_cap_str": "..."
}
```

## STEP 2 — KB 읽기 (read-only, 현재 매크로/섹터 맥락)

지정된 KB 파일 + 공통:
`knowledge-base/market/daily_snapshot.md`, `knowledge-base/market/regime.json`,
`knowledge-base/macro/us_monetary_policy.md`, `knowledge-base/macro/us_economy.md`

## STEP 3 — 독립 분석 (한국어, 전문 애널리스트 톤, 한글 비중 ≥80%)

출력 폴더에 다음 .md 파일 작성:

- `company.md` — 기업개요 + 해자(Moat) 평가 (Wide/Narrow/None + 근거)
- `financial.md` — 실적 추이·수익성·밸류에이션(PER/PBR 등)·목표주가 산출 근거
- `business.md` — 산업 동향·경쟁구도·TAM
- `momentum.md` — 가격/추정치 모멘텀·수급·컨센서스·이벤트 촉매
- `risk.md` — 리스크(재무/사업/규제/매크로/테일), Devil's advocate 관점
- `scorecard.md` — 10항목 가중 스코어카드 표 + **종합점수 NN/100** + **투자등급**(강력매수/매수/중립/매도/강력매도) + ATR 기반 손절/목표가

`scorecard.md` 에 다음 2개 섹션 **의무 포함**:

- **§ Confidence Interval** — 목표가 ±X%, 스코어 ±N점
- **§ 약한 가정 3개 (Most Fragile Assumptions)** — 결론을 뒤집을 핵심 가정 3개, 각 "반증 시 영향" 1줄

## STEP 4 — HTML 리포트 생성

먼저 계약 확인: `analysis/TSLA_Tesla_v5/gen_report.py` 를 Read 하여 `data` dict 키 구조를 그대로 따른다.
(TSLA 는 BLIND 샘플이며 비교 대상 아님 — 키 구조만 참고)

`analysis/{폴더}_v{N}/gen_report.py` 를 작성:

```python
# -*- coding: utf-8 -*-
import sys
ROOT = "/Volumes/외장SSD/클로드 AI 폴더/작업폴더/종목분석 에이전트"
sys.path.insert(0, ROOT)
from report_template import generate_report
data = { ... }   # TSLA 샘플과 동일한 키들을 너의 분석으로 채움
generate_report(data, output_path=ROOT + "/reports/{티커}_{영문폴더명}_20260616.html")
```

data dict 필수 키: ticker, name, date="2026-06-16", asset_type="주식", currency, score, grade,
current_price, market_cap, per, low52, high52, extra_kpis, stop_loss, target_price, atr,
executive_summary, company_overview, moat_rating, moat_details, fin_years, revenue_data,
op_income_data, fin_unit, financial_analysis, valuation, valuation_table, momentum,
consensus_table, business_analysis, competition_table, scorecard_items(=[[항목,점수,만점],...]),
thesis({claim,consensus,variant,falsifier,action,grade_line}).

- executive_summary 또는 헤더에 "재분석 v{N} (이전 v{N-1} 비교 미포함)" 표기.

실행 + 검증:

```bash
cd "ROOT" && python3 analysis/{폴더}_v{N}/gen_report.py && ls -la "reports/{티커}_{영문폴더명}_20260616.html"
```
