### #6 WTI ↔ BEI — 브리핑 반영 포인트

**핵심:** 이란 특사 취소 → WTI ~95~96 재급등. BEI(US10Y 대리) 4.33% 보합 = BEI 미추종. 서비스 인플레 독립 고착 구조 3주째 확인.

**1차→2차→3차 효과 연쇄:**
- 1차: WTI 급등 → 에너지 CPI 상방
- 2차: 서비스 인플레 독립 고착(PMI 서비스 입력비용 가속) → WTI 하락해도 Core PCE 자동 하락 불가
- 3차: IEA "역대 최대 에너지 공급 충격" 경고 → 구조적 에너지 상방 리스크 = Fed 인하 경로 추가 지연 근거

**briefing-lead에게:** "WTI가 $85로 하락해도 Core PCE는 3.0% 근처 유지 가능" 논리를 B-4 서프라이즈 섹션에 연결 필요. 4/30 Core PCE 방향이 이 구조를 공식 확인하는 이벤트임을 명시.
