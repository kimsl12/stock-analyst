## 🎯 contrarian-card 후보 (과소평가 포인트 1건)

**과소평가: "유가發 디스인플레이션" — 시장이 Core PCE 매파에만 매달려 헤드라인 둔화 경로를 놓치고 있다**

- **시장 컨센서스**: Core PCE 3.4% 상회 → Fed 매파 정당 → 금리·달러 강세. 인플레 = 끈적함이라는 일방향 내러티브.
- **과소평가된 사실**: 호르무즈 6/20 재폐쇄 주장이 6/22~24 이틀 연속 선박 미공격으로 사실상 안정화 → WTI $70(-4.2%, 3월 피크 $118서 -41%). 에너지 +23.5% 가 5월 헤드라인 CPI 4.2% 를 끌어올린 주범이었던 만큼, **6월 유가 급락은 헤드라인 인플레의 빠른 하향 압력**. 10Y BEI 2.18%(전주 2.26%서 하락)·미시간 1y 기대 4.6%(5월 4.8%서 하락)가 이미 신호.
- **왜 시장이 놓치나**: Fed dot plot 매파 충격(6/17)의 잔상 + BoFA 3회 인상 경고(6/22)가 헤드라인을 지배 → 시장 심리가 "인플레 추가 악화"에만 고정됨. 리스크오프 레짐(2일째)·F&G 25.9(공포)가 비관 편향을 증폭.
- **반전 조건**: 오늘 Core PCE 부합~하회 + 헤드라인 PCE 둔화 동반 → "6월 인플레 피크" 인식 점화 → HV1 약화 개정 제안 트리거. 단 Core(서비스) 끈적함이 에너지 둔화를 상쇄하면 이 논리는 무효 → **Core vs 헤드라인 괴리 폭이 검증 핵심**.
- ⚠️ 리스크: Core PCE 가 헤드라인과 무관하게 3.4%+ 상회하면 contrarian 논리 즉시 폐기. 어디까지나 "시장이 한쪽만 본다"는 비대칭 지적이지 방향성 단정 아님.
