## B-9. 글로벌 매크로 핵심 시사점

### 시사점 1: "ISM 서비스 가격 70.7%가 NFP보다 중요한 이유"

시장은 NFP에 집중하지만, ISM 서비스 가격지수 70.7%(2022년 이후 최고)가 에너지와 **독립적인** Core 인플레 고착을 시사한다는 점이 더 구조적이다. 이란 합의가 에너지 헤드라인 CPI를 완화하더라도, 서비스 인플레(임대·의료·금융서비스)의 고착은 Core PCE 3.2%(3월)의 하락 속도를 제한한다. 5/12 CPI에서 "에너지 CPI 하방 + Core CPI 상방" 괴리 발생 시, Fed는 Core에 반응하므로 인하 경로는 오히려 후퇴한다. [ISM, FRED Core PCE, BLS]

**결론:** NFP는 단기 시장 반응 트리거이나, ISM 서비스 가격 70.7%가 Fed 정책 경로의 진짜 결정 변수. 시간축 중기(3~6개월) 관점에서 채권 롱 포지션 진입은 Core PCE 하락 확인 후가 안전.

### 시사점 2: Fed 이원 권력 구조 — Warsh 인준 D-3

Warsh 상원 본회의 표결 5/11주 예상. 파월 의장직 만료(5/15) 직전 인준 완료 시 Fed 이원 권력(파월 이사+Warsh 의장) 구조 공식화. Warsh는 "트럼프 꼭두각시 안 된다" 발언(상원 인준청문회)으로 독립성 강조했으나, 트럼프의 인하 압박 구조는 불변. 매 FOMC마다 정책 서프라이즈 확률 구조적 상승 → 국채 변동성(MOVE 인덱스) 확대 요인. [CNBC, CNN, macro/us_monetary_policy.md]

**레짐 판정:** Late Cycle + 인플레 재가속 + 지정학 불확실성 + Fed 이원 구조 = **위험등급 4/5 유지**
