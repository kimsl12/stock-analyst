## 4. 4축 교차 테마 (이브닝 갱신)

### G-2(정치) + G-4(에너지) 교차: "디스인플레 환상" 리스크

호르무즈 해소(G-4)로 에너지 CPI 하방 반전이 확보됐으나, 정치축(G-2)에서 Core 인플레 고착(관세 잔여 + ISM 가격 급등)이 동시 진행. 5/13 4월 CPI에서 헤드라인은 하방 서프라이즈 가능하나 Core는 상방 유지 = "디스인플레 환상". 시장이 헤드라인에 반응해 인하 기대를 과도 선반영할 경우, 4/30 Core PCE 3%+에서 역전 충격.

### G-1(지정학) + G-3(기술) 교차: "양자 촉매 + AI CapEx 슈퍼사이클"

NVIDIA Ising 오픈소스 QEC 모델(4/14 발표)이 양자컴퓨팅 섹터에 촉매 공급. IonQ +20% 주간 급등. 동시에 TSMC 2nm 양산 + CoWoS 13만wpm 확장 + HBM 전량 매진 = AI 인프라 투자는 지정학 노이즈와 무관하게 가속. Waller 4/17 연설에서도 "데이터센터 CapEx 강세"를 GDP 지지 요인으로 명시.

- 기술 단계 판정: NVIDIA Ising QEC = 시제품(연구기관 채택 단계). 양자컴퓨팅 자체는 시제품 단계이나, AI-양자 교차 인프라는 상용화 초기 진입.

### G-2(정치) + G-1(지정학) + G-4(에너지) 3축 교차: "신현승 한은총재 취임과 에너지 비용 하락의 교차"

신현승 총재의 매파 성향("현 2.50%는 중립금리 중간. 물가안정 우선")이 에너지 비용 하락(G-4)과 교차. 유가 하락으로 CPI 상방 압력이 완화되면 인상 명분은 약화되나, Core CPI 고착 + 환율(1,484원) + 가계부채 관리 필요성이 동결 장기화 근거를 제공. 매파 총재 하에서 "인하 기대 소멸 + 동결 고착" = KOSPI 밸류에이션 상한 제약 요인.

등급 변화 핵심: 리스크의 **총량**은 감소했으나 **성격**이 변화. "지정학 충격(외부/돌발)"에서 "정책 리스크(내부/점진)"로 전환. 점진적 리스크는 시장이 과소평가하는 경향이 있어 위험.
