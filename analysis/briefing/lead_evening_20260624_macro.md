   - **2차: 강달러 → 원화 1,535원·이머징 자본유출 압력 + 일본 BOJ 1.0% 인상과 맞물려 엔캐리 청산 변수(USD/JPY 161)**

2. **AI/반도체 디레이팅 + 순환금융 균열**
   - 1차: NVDA·SOX 급락, KOSPI 반도체 서킷브레이커 전파
   - **2차: AI capex $600~725B(2026E)를 채권발행으로 조달(SpaceX $25B, CDS 사상최대) → 신용 사이클 리스크 전이 경로 노출**
   - **3차: 한국 수출 38~42% 반도체 쏠림 = 미 SOX 변동성 직접 노출, 코스피 9,000→8,200 변동성이 외국인 수급·원화로 역류**

3. **호르무즈 통항 재개 (에너지 완화)**
   - 1차: WTI $73·Brent $77로 유가 하락 → 헤드라인 인플레 1차 압력 완화
   - **2차: 유가 완화가 5월 CPI 4.2%(에너지 +23.5% 기여) "피크론"을 지지 → 그러나 Core CPI 2.9%(주거·서비스) 끈적함은 별개 → Fed 매파 명분 완전 해소 아님**

- 6/25 Core PCE가 3.2~3.4% 박스권(컨센 부합~소폭 상회) → Fed 인상 베팅 유지되나 "3회 인상" 컨센화는 아직. 시장은 1~2회로 프라이싱
- 빅테크 디레이팅 + 중소형·은행·가치주 로테이션 지속. VIX 18~22 박스, 10Y 4.4~4.6%
- 호르무즈 통항 점진 정상화·유가 $72~80 박스 → 에너지 인플레 완화 우세
- 한국: 반도체 수출 호조(펀더멘털)와 코스피 변동성(밸류·외국인) 디커플링 지속

### 상방 시나리오 (확률 ~25%) — "PCE 둔화 + 유가 안정 = 안도 반등"

- 6/25 Core PCE 3.1% 이하 둔화 + 호르무즈 완전 정상화·유가 $70대 안착 → "인플레 피크" 내러티브 강화
- BoFA 3회 인상 콜이 과도했다는 평가 → 인상 베팅 완화, 10Y 4.4% 하회 → 빅테크 밸류 안도
- VIX 16대 진정, S&P 반등. AI capex 펀더멘털(McKinsey 2.6~4.7% 생산성 실증) 재부각

### 하방 시나리오 (확률 ~20%) — "PCE 재가속 + 호르무즈 재격화 = 스태그플레이션 공포"

- 6/25 Core PCE 3.5%+ 재가속 → 6/17 점도표 인플레 3.6% 정당화 → BoFA 3회 인상 컨센화
- 동시 호르무즈 이행 분쟁 재격화·유가 $90~100 갭 → 헤드라인 인플레 재점화
- 10Y 4.6%+·30Y 5% 안착, AI 순환금융 균열(SpaceX형 채권 광풍 신용 스트레스) 표면화 → Mag7 추가 디레이팅, VIX 25+
- 한국 반도체 쏠림이 SOX 급락 직격 → 코스피 추가 변동성
