## 4. 이란 신제안(호르무즈 재개방 + 핵협상 지연) 영향 분석

### 4-3. 2차 효과 -- 러시아 변수

아라그치의 모스크바 방문(4/27)은 단순 외교 관례가 아님:
- **러시아는 이란전쟁 장기화의 수혜자**: (1) 글로벌 유가 상승 -> 러시아 에너지 수출 수혜, (2) 미군 중동 집중 -> 우크라이나 전선 미국 관심 분산, (3) 이란 무기 공급 대가로 이란시장 접근
- **러시아가 중재에 개입할수록 타결은 지연**: 미국 입장에서 러시아 참여 중재는 수용 불가. 오만이 대안이나 오만의 중재 레버리지는 파키스탄보다 약함
- **3차 효과:** 이란-러시아 연대 강화는 **5/14~15 미중 정상회담**에서 중국의 대이란 입장에도 영향. 미국이 중국에 이란 압박 카드를 사용할 유인 증가 -> 미중 정상회담 의제 복잡화

## 5. "서비스 인플레 고착" 구조 전환 점검 (WTI-BEI 디커플링)

### 5-1. 현재 상태: **"잠복기 후반"**

```
[에너지 가격 급등] ---(2~3개월 시차)---> [제조업 비용 전이] ---(1~2개월 시차)---> [서비스업 비용 전이] ---(1~2개월 시차)---> [근원 인플레 고착]
      ^완료                                    ^진행 중                                ^초기 진입                              ^미도달
```

- WTI 급등(2월말~): 에너지 CPI MoM +10.9%, 가솔린 +21.2% [BLS]
- ISM 제조업 가격 78.3(2022.06 이후 최고): 제조업 비용 전이 **진행 중** [ISM]
- ISM 서비스 가격 70.7(+7.7p, 2022.10 이후 최고): 서비스업 비용 전이 **초기 진입** [ISM]
- Core CPI 2.6%, Core PCE 3.0%: 근원물가는 아직 "고착" 단계 미도달 [BLS, BEA]
- 5Y BEI 2.58%: 채권시장은 "일시적" 판단 유지 [FRED]

### 5-2. 4/30 Core PCE가 결정적 분기점

| Core PCE 결과 | 해석 | Fed 경로 | 시장 반응 |
|-------------|------|---------|---------|
| <2.8% | 에너지 전이 제한적. "일시적" 확인 | 6월 인하 재점화 | S&P +1~2%, DXY 하락 |
| 2.8~3.0% | 컨센서스 범위. 중립 | 9~11월 인하 유지 | 중립 |
| 3.0~3.2% | 서비스 전이 초기 확인 | 인하 지연. 연내 0~1회 | S&P -1~2%, VIX 상승 |
| **>3.2%** | **서비스 인플레 고착 진입** | **연내 인하 소멸** | **S&P -3%, VIX 22+** |

### 5-3. 핵심 판단

WTI $95+ 환경에서 4/30 Core PCE가 **3.2%를 상회하면**, "에너지 인플레는 일시적"이라는 Fed 프레임이 위협받고, 5Y BEI도 2.8%+ 이탈 시작 가능. 이 경우:
- Fed 연내 인하 **완전 소멸** (dot plot 중간값 1회 인하 무력화)
- 10Y 4.5%+ 상승 -> 성장주 밸류에이션 재조정
- "스태그플레이션" 내러티브 공식화 -> Risk-off

현재 확률 추정: Core PCE 3.2%+ **약 30~35%** [WTI $95+ 반영 시 상방 리스크 증가]
