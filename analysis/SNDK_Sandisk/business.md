# SanDisk (SNDK) 사업 분석

## 1. 산업 구조
- 글로벌 NAND 시장: ~$77.8B (2026E), CAGR ~15%
- 6개 플레이어 과점: 삼성(31%), SK(20%), Kioxia(17%), Micron(15%), SanDisk(13%), YMTC(4%)
- AI 데이터센터가 수요 핵심 (서버 SSD, 학습 데이터 저장)

## 2. NAND 수급 타이트
- 수요 성장: +20~22% (bit 기준) → AI 데이터센터 드라이브
- 공급 성장: +15~17% → CAPEX 보수적 + 전환 지연
- **수급 갭 +5%p → 가격 상승 사이클 지속**

## 3. 메가트렌드
1. **AI 데이터센터**: 학습/추론 데이터 저장 → Enterprise SSD 수요 폭발
2. **엣지 AI**: 온디바이스 모델 → 모바일/PC 스토리지 확대
3. **자율주행**: 차량당 TB급 스토리지 필요
4. **클라우드 스토리지**: 하이퍼스케일러 CAPEX 지속

## 4. SanDisk 차별화: Pure-Play 프리미엄
- **글로벌 유일 상장 NAND 전문 기업** → 투자자에게 NAND 직접 노출 수단
- 경쟁사(삼성/SK/Micron)는 DRAM/HBM/로직 매출이 더 큰 복합 기업
- NAND 호황 시 주가 베타 극대화 (12개월 30배 증거)
- 반면 NAND 불황 시 하방 리스크도 극대화 (양날의 검)

## 5. 경쟁 심층
| 경쟁 요인 | SanDisk 포지션 |
|----------|---------------|
| 기술 (적층) | BiCS Flash (Kioxia JV), BiCS8 전환 중 |
| 제조 규모 | 5위(13%), 삼성(31%) 대비 열위 |
| Enterprise SSD | 성장 중이나 삼성/SK 대비 후발 |
| Consumer | 브랜드 1위 (microSD, USB) |
| 원가 경쟁력 | 규모 열위로 구조적 불리 |
