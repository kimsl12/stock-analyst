# SanDisk (SNDK) 리스크 분석

## 1. 밸류에이션 과열 리스크 (최대)
- 12개월 30배, YTD +163% → 역사적으로 극단적
- 현재가 $856 > 컨센서스 평균 $790 → 업사이드 소진
- PSR 10.5x는 Micron(4.5x) 대비 2.3배 → pure-play 프리미엄 과도?
- **10~30% 조정 가능성 상존**
- 영향도: ⭐⭐⭐⭐⭐ | 발생확률: 50%

## 2. NAND 사이클 전환 리스크
- 현재 수급 타이트(+22% vs +17%) → 하반기~2027 공급 과잉 전환 가능
- YMTC 증설 + 삼성/SK 투자 확대 시 가격 급락
- NAND 역사적으로 2~3년 주기 사이클 반복
- 영향도: ⭐⭐⭐⭐⭐ | 발생확률: 35%

## 3. BiCS8 전환 실행 리스크
- 차세대 공정 전환 지연/수율 문제 → 원가 경쟁력 약화
- 독립 기업 1년차 → R&D 실행력 미검증
- 영향도: ⭐⭐⭐⭐ | 발생확률: 25%

## 4. 규모 열위 리스크
- 점유율 13%(5위) vs 삼성 31% → 가격 전쟁 시 취약
- CAPEX 경쟁에서 대형사 대비 불리
- 영향도: ⭐⭐⭐ | 발생확률: 상존

## 5. 테일 리스크
- **NAND 가격 50% 급락**: 공급 과잉 + 수요 둔화 → 주가 -50~60%
- **중국 YMTC 덤핑**: 서방 시장 저가 공세 → 마진 압축
- 발생확률: 10~15%

## 6. 리스크 종합: C+ (5.5/10)
- 밸류에이션 극단적 고평가가 최대 리스크
- NAND 사이클 전환 시 하방 매우 큼 (pure-play 양날의 검)
- 재무건전성(순현금)이 리스크 완화 요인
