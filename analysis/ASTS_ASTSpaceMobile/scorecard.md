## 6. 추천 근거 (수치 기반 종합)

### 강력한 매수 근거 5가지
1. **광대역 D2D 단독 사업자**: 셀당 120Mbps로 Starlink DTC(10Mbps) 대비 12배 우위
2. **40+ 통신사 락인**: AT&T·Verizon·Vodafone·Rakuten 등 글로벌 대형 통신사 다중 락인
3. **2026 Q2 매출 변곡점**: AT&T FirstNet 베타 시작 → 분기 매출 6배 점프 가능
4. **순현금 $1.08B**: 22개월 런웨이로 단기 자금 위험 낮음
5. **컨센서스 +23% 상승여력**: 5개사 평균 목표가 $107 (현재 $86.91)

### 신중 매수 근거 5가지
1. **PSR 190배의 거품**: 동종 평균 대비 6배 이상, 성장 미달 시 급락
2. **ATR 10.22%의 극변동성**: 일반 주식의 5배, 분할매수·손절 필수
3. **Starlink V2 위협**: 2027 중반 광대역 D2D 출시 시 시총 -45% 가능
4. **공매도 비율 18~22%**: 추가 공매도 보고서 시 단기 -15~20%
5. **2027 추가 자금조달 가능성**: 신주 5천만주 발행 시 EPS 13% 희석
