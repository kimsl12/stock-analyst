## 3. 자율주행 산업 (Tesla Robotaxi vs Waymo vs Apollo Go)

### 3-1. 경쟁 매트릭스 (KB auto.md L172~177)

| 업체 | 2026 운영 규모 | 차량 비용 | unit-economic |
|------|---------------|----------|--------------|
| **Waymo** | 2,500대+ (CA·TX·FL → Tokyo → London) | $80K+ | 베이징·우한 unit econ 근접 (Baidu) |
| **Tesla Robotaxi** | Dallas·Houston 무인 개시 (2026-04-18) | Model Y $40K / Cybercab 미공개 | 검증 단계 (2026 H2~2027) |
| **Baidu Apollo Go** | 누적 2,000만회 + 주당 30만회 + 20개 도시 | RT6 $30K (Waymo 1/3) | 우한·베이징 unit econ 근접 |

### 3-2. 핵심 차별화 요소

**Tesla의 강점**:
- **데이터 양** — 신차 인도마다 데이터 누증 (100억 mile+ FSD 데이터)
- **VertIcalIntegration** — 차량+칩+SW+충전망 통합
- **Cybercab 양산** — 무인 전용 차량 가성비 (2시트 양산형)

**Tesla의 약점**:
- **안전 인증 갭** — Waymo L4 미국 5개 주 안전 운영 vs Tesla 카메라-only L2+
- **규제 인증 속도** — NHTSA 인증 Waymo·Apollo Go 가 선행
- **법적 책임 구조** — 사고 시 Tesla 직접 책임 vs Waymo 인수책임 보험 구조 확립

### 3-3. 시장 규모 (옵션 밸류 검증)
- 글로벌 ride-hailing TAM 2030 추정 $400~600B (Uber·Lyft·DiDi 합산)
- Robotaxi 전환 시 비용 50~70% 절감 가능 (운전자 인건비 제거)
- Tesla Robotaxi 5% 점유 가정: $20~30B 매출 + OPM 40~50% × PER 25x = **$200~350B SOTP**
- Tesla Robotaxi 15% 점유 가정 (낙관): $60~90B 매출 + OPM 50% × PER 25x = **$750~1,200B SOTP**

> **결론**: Robotaxi 점유 5~15% 검증 시 Tesla 시총 $200B~$1.2T 옵션 가치 추가. **현 시총 $1.63T 가 정당화되는 결정적 변수**.

## 6. 산업 트렌드 결론

자동차 산업은 **EV 침투율 18.5% → 22% 가속 + Big3 EV 후퇴 + 중국 가격전 survival + HEV 반사효과 + 자율주행 상용화 본격** 의 5중 변곡점. Tesla는 BEV-only OEM 으로:
- **Big3 후퇴**의 직접 수혜자 (미국 BEV 점유 방어)
- **중국 가격전·HEV 반사효과**의 직접 피해자 (Shanghai 매출 압박 + 미국 HEV 흡수)
- **자율주행 상용화**의 핵심 옵션 보유자 (Robotaxi 무인 개시 + Cybercab 양산)

**핵심 변수**: Robotaxi unit-economic 검증 (2026 H2~2027) — 5~15% 점유 검증 시 시총 $200B~$1.2T 옵션 추가 → 현 $1.63T 정당화. 검증 실패 시 자동차 SOTP만 인정되어 시총 $300~500B 으로 -70% 수렴 가능.
