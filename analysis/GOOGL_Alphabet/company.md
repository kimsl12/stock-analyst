### 2. 주식 클래스 구조 (3-Class Structure)
| 클래스 | 티커 | 의결권 | 비고 |
|--------|------|--------|------|
| Class A | GOOGL | 주당 1표 | 일반 투자자 거래 |
| Class B | 비상장 | 주당 10표 | 래리 페이지 + 세르게이 브린 보유 → 의결권 약 51% 지배 |
| Class C | GOOG | 없음 | 경제적 가치는 Class A와 동일, 의결권만 없음 |

> 경영진 교체나 M&A 등 주요 의사결정에서 소수주주 영향력 제한. 단, 창업자의 장기적 비전 추구 가능이라는 양면성 존재.

## Part B: 경제적 해자(Moat) 심층 분석

### Moat 종합 등급: **Wide Moat** (넓은 해자)

### Moat 원천별 분석

#### 1. 네트워크 효과 — 등급: ★★★★★ (매우 강함)
| 네트워크 | 규모 | 해자 깊이 |
|---------|------|----------|
| Google Search | 글로벌 검색 점유율 ~90% | 더 많은 사용자 → 더 좋은 검색 결과 → 더 많은 광고주 |
| YouTube | MAU 25억+ | 크리에이터 콘텐츠 → 시청자 → 광고주 3면 네트워크 |
| Android | 기기 30억+ 대 | 앱 생태계 → 개발자 → 사용자 선순환 |
| Google Maps | MAU 20억+ | 사용자 데이터 → 지도 정확도 → 더 많은 사용자 |
| Gmail/Workspace | 유료 사용자 1,000만+ 기업 | 기업 전환 비용 높음 |

> **핵심:** 알파벳은 인터넷 역사상 가장 강력한 다중 플랫폼 네트워크 효과를 보유. 검색-YouTube-Android-Maps-Gmail이 상호 강화하는 생태계.

#### 2. 무형자산 (브랜드/기술/데이터) — 등급: ★★★★★ (매우 강함)
- **브랜드:** "Google"은 글로벌 인지도 1위 브랜드 중 하나. "구글링"이 검색의 동의어
- **기술 자산:** Gemini LLM, TPU 칩, TensorFlow/JAX 프레임워크, Borg/Kubernetes
- **데이터 자산:** 글로벌 검색 쿼리, YouTube 시청 데이터, Android 사용 데이터, Maps 위치 데이터 → AI 학습에 최대 우위
- **특허:** 40,000+ 특허 포트폴리오

#### 3. 전환 비용 — 등급: ★★★★☆ (강함)
| 제품 | 전환 비용 | 설명 |
|------|----------|------|
| Google Workspace | 높음 | Gmail, Drive, Docs, Calendar 통합 → 전사적 마이그레이션 비용 막대 |
| Google Cloud (GCP) | 높음 | 데이터·워크로드 마이그레이션 비용 + Vertex AI 종속 |
| Android | 중간 | iOS 전환 시 앱/데이터 이전 번거로움, 그러나 불가능하지는 않음 |
| Google Search | 낮음 | 기술적 전환은 쉬우나, 습관적 사용 고착 효과 |

#### 4. 비용 우위 — 등급: ★★★★☆ (강함)
- **규모의 경제:** 글로벌 최대 데이터센터 네트워크 → 단위 연산 비용 업계 최저 수준
- **TPU 자체 제조:** GPU 의존도 경감, AI 추론 비용 경쟁사 대비 20~30% 절감 추정
- **광고 CPC 효율:** 검색 독점 → 광고주 대안 부족 → 가격 결정력
- **R&D 효율:** $610억 R&D 투자 (매출의 15%) → 절대 규모는 크지만 매출 대비 비율은 적정

#### 5. 효율적 규모 — 등급: ★★★☆☆ (중간)
- 검색 시장에서 사실상 독점이나, DOJ 반독점 소송으로 규제 리스크 존재
- 클라우드 시장은 3위 → 효율적 규모의 이점이 제한적

### Moat 트렌드: **안정 (Stable)**
- AI 전환이 해자를 강화할 수도, 약화할 수도 있는 전환기
- Gemini + TPU 전략이 성공하면 해자 확대
- AI 검색이 전통 검색을 완전 대체하면 광고 모델 변화 리스크
- 반독점 판결이 해자의 법적 보호 여부를 결정할 핵심 변수

### Moat 위협 요인
1. **DOJ 반독점:** Chrome 분리, 디폴트 검색 계약 금지 시 검색 점유율 훼손
2. **AI 네이티브 검색:** Perplexity, ChatGPT 등 AI 기반 검색이 Google 검색 대체 시도
3. **Cloud 경쟁:** AWS/Azure가 AI 기능에서 더 빠르게 혁신할 경우 GCP 성장 둔화
4. **오픈소스 LLM:** Llama, DeepSeek 등이 Gemini의 기술 우위를 약화

### Moat 기회 요인
1. **AI가 검색 해자를 오히려 강화:** Google의 방대한 데이터가 AI 검색 품질의 핵심 차별화 요소
2. **TPU의 비용 우위:** 자체 칩이 GPU 대비 20~30% 비용 절감 → 클라우드 경쟁력 강화
3. **Waymo 선점:** 자율주행 레벨 4 상용화 선두 → 향후 교통 플랫폼 독점 가능
