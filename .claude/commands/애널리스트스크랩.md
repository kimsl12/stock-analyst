$ARGUMENTS 인자로 **웹 모드 스크랩**을 실행해줘.

## 명령 정보

- **모드:** 웹 모드 (analyst-scraper)
- **입력:** WebSearch / WebFetch (인자로 지정한 소스·키워드·기간)
- **산출물:** `reports/analyst/items/{id}/{meta.json, source.html | source.pdf, summary.html}` + `reports/analyst/index.html`

## 인자 해석

- `--source` (기본: all): 수집 소스 한정. `ib` (GS·JPM·MS·BoA·BlackRock 공식) / `media` (Bloomberg·CNBC·Reuters 인용) / `korea` (한경 컨센서스·Naver 리서치 PDF) / `yt` (YouTube 분석가) / `all` (전체)
- `--keyword` (선택): 특정 종목/주제 (예: NVDA / 반도체 / S&P500). 미지정 시 거물 8인 weekly + 최근 핫 토픽
- `--days` (기본 7): 최근 N일 이내 자료만
- `--limit` (기본 10): 항목 최대 개수 (소스별 sub-limit 자동 분배)
- `--no-deploy` → deploy 스크립트 호출 생략

## analyst-scraper 에 전달할 컨텍스트

```
mode: web
sources: {parsed --source}
keyword: {parsed --keyword or default-watchlist}
days: {parsed --days}
limit: {parsed --limit}
deploy: true (--no-deploy 없으면)

watchlist (--keyword 미지정 시 기본):
  - 거물 분석가: Marko Kolanovic (JPM), Mike Wilson (MS), David Kostin (GS),
                Michael Hartnett (BoA), Tom Lee (Fundstrat),
                Mohamed El-Erian (Allianz), Howard Marks (Oaktree)
  - 핫 토픽 (자동 후보): NVDA, Magnificent 7, S&P 500 outlook, 인플레이션, FOMC, BTC

source_endpoints:
  ib_official:
    - https://www.goldmansachs.com/insights/
    - https://www.jpmorgan.com/insights
    - https://www.morganstanley.com/ideas
    - https://www.blackrock.com/institutions/en-us/insights
  korea_brokerage:
    - https://consensus.hankyung.com/  (한경 컨센서스)
    - https://finance.naver.com/research/  (Naver Finance 리서치)
  media:
    - WebSearch with site:bloomberg.com / site:cnbc.com / site:reuters.com / site:wsj.com
  youtube:
    - WebSearch site:youtube.com "Bloomberg Surveillance" / "CNBC Half Time"

workflow (analyst-scraper):
  1. 소스별 후보 URL 수집 (WebSearch + WebFetch)
  2. 각 후보 마다:
     a. item_id 결정 + 중복 체크 (Glob items/{id})
     b. 메타데이터 작성 (analyst-scraper 가이드의 source 매핑 + license_note 강제)
     c. items/{id}/ 생성
     d. (한국 증권사 PDF) python scripts/process_analyst_web.py download-pdf
        (그 외) Write items/{id}/source.html 로 원문 텍스트 보존
     e. Write items/{id}/meta.json
     f. python scripts/process_analyst_web.py commit --item-id {id}
  3. 모두 처리 후 보고

저작권 안전:
  - IB 공식 / 미디어 인용 → 원문 PDF/기사 X, 본인 정리 + 헤드라인 + 출처 링크
  - 한국 증권사 무료 공개 PDF → 다운로드 가능 (license_note=public_official)
  - YouTube → 영상 임베드 X, 제목·설명·요약만 (license_note=media_quote_only)

required_extras:
  - 결과 보고: 추가된 N건 표 (소스 / 종목 / 권고 / 1줄)
  - 스킵 사유 명시 (중복·저신뢰·접근불가)
  - 사이트 반영은 deploy_cloudflare.sh 가 처리
```
