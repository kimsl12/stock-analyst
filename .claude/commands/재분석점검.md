# 재분석 점검 (Re-analysis Audit)

$ARGUMENTS 일 이상 경과한 분석을 탐지하고 재분석 우선순위를 매긴다. **인자 생략 시 기본 14일 기준**.

## 실행 순서 (stock-analyst-lead가 직접 수행 — 서브에이전트 호출 불요)

### Step 1: 임계값 확정

```bash
THRESHOLD_DAYS=${ARGUMENTS:-14}
echo "임계 경과일: ${THRESHOLD_DAYS}일"
```

### Step 2: session-bootstrap.md에서 분석 목록 + 경과일 계산

```bash
today=$(date +%Y-%m-%d)
today_sec=$(date -j -f "%Y-%m-%d" "$today" "+%s" 2>/dev/null || date -d "$today" "+%s")

# "| {종목} | {날짜} | {스코어}" 패턴 추출 — analysis/ 유효 파일 표
grep -E "^\| [A-Z0-9_가-힣]+" session-bootstrap.md | \
awk -F'|' '{ print $2 "|" $3 "|" $4 }' | while IFS='|' read -r stock date rest; do
    stock=$(echo "$stock" | xargs)
    date=$(echo "$date" | xargs | cut -c1-10)
    [[ -z "$date" || ! "$date" =~ ^2026 ]] && continue
    date_sec=$(date -j -f "%Y-%m-%d" "$date" "+%s" 2>/dev/null || date -d "$date" "+%s")
    days=$(( (today_sec - date_sec) / 86400 ))
    echo "$days|$stock|$date|$(echo $rest | xargs)"
done | sort -rn -t'|' -k1
```

### Step 3: 섹터 KB 최근 갱신 확인 (매크로 트리거)

```bash
# knowledge-base/industry/*.md + macro/*.md 중 최근 7일 내 갱신된 파일 목록
find knowledge-base/industry knowledge-base/macro -name "*.md" -mtime -7 -type f 2>/dev/null | \
    xargs -I {} basename {} .md
```

이 섹터 파일 목록을 아래 매핑 테이블과 교차:

### Step 4: 우선순위 3단계 분류

| 분류 | 조건 | 색상 |
|------|------|-----|
| 🔴 HIGH | 경과 ≥ THRESHOLD OR (경과 ≥ 7일 AND 섹터 KB 갱신 있음) | 즉시 재분석 |
| 🟡 MEDIUM | 경과 ≥ THRESHOLD × 0.7 (기본 10일+) | 재분석 고려 |
| 🟢 LOW | 경과 < THRESHOLD × 0.7 | 유효 |

## 주의사항

- 서브에이전트 호출 **금지** (이 명령은 탐지·보고 전용, 분석 실행 아님)
- 새 파일 생성 금지 (임시 파일 포함)
- 결과는 대화창에만 출력, session-bootstrap.md 수정 금지

## 실패 케이스

- session-bootstrap.md 없음 → "Bootstrap 파일 미발견 — 종목분석 실행 이력 없음" 안내
- KB mtime 확인 실패 → KB 트리거는 스킵하고 경과일 기준만 적용
- 모든 분석이 임계값 이하 → "🟢 모든 분석 유효 (최장 {n}일 경과) — 재분석 불요" 안내
