### 이슈 4: R:R < 1.5 진입 보류 자동 태깅 (scorecard-strategist)

| -------- | ------------------------------------ |
| ≥ 2.0    | (태그 없음)                          |
| 1.5~1.99 | 🟡 Acceptable                        |
| 1.0~1.49 | 🟠 **⚠️ 진입 보류 권고**             |

## ATR 손절/목표가 시스템

- STEP 1: `initial_stop = MAX(고정비율 8%, ATR14 × 2)`
- STEP 2: 트레일링 전환 = +10% 도달 시
- STEP 3: `trailing_stop = 고점 - ATR×2` (래칫, 하향 금지)
- STEP 4: `target = entry + risk × 손익비(기본 2)`
- SSOT: `stop-loss-rules.md`
